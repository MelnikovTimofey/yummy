# Handoff: «Намиксуй» с нижней панелью и пошаговым «Назад» (#350)

Мокап по скиллу `atelier-feature-design`, шаг 3. На экране «Намиксуй» видна нижняя
панель гостя, «Назад» отменяет прошлый ход. Бриф и критерии приёмки — в
[issue #350](https://github.com/MelnikovTimofey/yummy/issues/350). Решение пересматривает #293.

**Перерисован под канон #348** (2026-10-23). Первая версия мокапа (`8ef197a8`) вышла
раньше, чем смерджили канон (#358, `1cafc121`). Теперь мокап сделан по срезу G3 «Миксер»
(#361) и мокапу «стало» `design/design_handoff_ui_deslop/mockups-guest.html#shot=mixer-turn|mixer-reveal`:

- тексты: «Ход 1 из 3», «Основа, 40–70%»;
- у пустой чаши одна подсказка;
- нет гало экрана и кольца, пятен на картах и пунктира у пустой колоды;
- штампы «Беру» и «Дальше» без поворота и капса;
- подписи «Полки», «Гармония», «Название», «Доли»;
- карточка для мастера: плашка «Собран гостем, гармония 79», состав без middot и капса.

Нижняя панель и пошаговое «Назад» не изменились. Проверка высоты повторена на новой
вёрстке.

## Как открыть

Мокап подключает файлы из репо (`mixer.css` приложения, токены), поэтому нужен
статический сервер из корня репо:

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

Дальше открыть `http://localhost:8765/design/design_handoff_mixer_nav/mockups.html`.

- Доска состоит из трёх разделов:
  - ходы сборки на 375×812;
  - проверка высоты на 375×667;
  - карточка «Покажите мастеру» в двух вариантах.
- Каждый телефон — `iframe` точного размера. Поэтому `@media (max-height: 740px)` и
  container-запросы колоды срабатывают как на реальном экране.
- Метка над телефоном — высота колоды. Красная метка — колода меньше 200 px или низ
  экрана обрезан.
- `mockups.html#shot=<id>` — один телефон без доски. `id` совпадает с именем файла в
  `screens/`. Например: `base-812`, `twist-812`, `reveal-812`, `twist-line-667`,
  `master-nav-812`, `master-full-812`.
- `mockups.html#screen=<экран>&compact=1` — сам экран на всё окно.

## Файлы

- `mockups.html` — экран свёрстан на классах `apps/aroma-web`:
  - живой `apps/aroma-web/src/components/mixer/mixer.css` подключён ссылкой;
  - поверх него — блок правок G3 (#361), которых в `mixer.css` ещё нет. После #361 блок
    не нужен;
  - правила оболочки и панели скопированы из `apps/aroma-web/src/styles.css` (main после #359);
  - разметка повторяет `MixerScreen`, `SwipeDeck`, `TobaccoCard`, `MixerReveal`,
    `MixerMasterCard`, `BottomNav`.
- `screens/` — снимки всех телефонов (`<id>.png`) и трёх разделов доски (`board-*.png`).
- Данные — полка прода (снапшот 2026-10-21):
  - основа — Darkside Virgin Peach 2.0;
  - акцент — Darkside Bittersweet;
  - штрих — Black Burn Cane Mint.

  Черновое имя «Персик и лимон со льдом» собрано по правилу `draftMixName`.

## Что реализовать

Срез #350 идёт после #361: оба правят `components/mixer/**` и `aroma-smoke.spec.ts`.

1. **Панель на экране.** `App.tsx` рендерит `BottomNav` после `MixerScreen`, активен
   «Миксер». Панель — последний flex-элемент `.phone-shell`, как на остальных экранах.
   `.mixer` уже `flex: 1 1 auto; min-height: 0`: колода и док «Покурить» встают над панелью.
2. **«Назад» — откат хода.** Вернуть логику до #293 (`78e3cc08^`, `MixerScreen.back`):
   - **акцент** → основа. Основа снимается из чаши, колода хода начинается сначала,
     полки — из подбора;
   - **штрих** → акцент. В чаше остаётся основа;
   - **раскрытие** → штрих с двумя табаками. Так же после «Без штриха» и
     «Доверюсь мастеру»;
   - **основа** → `onExit()`, на экран, откуда пришли.

   Реплика — `say(TURNS[target].line)`. Пока `busy`, стрелка и панель ничего не делают.
3. **Уход через панель посреди сборки.** Чаша сбрасывается: `MixerScreen` размонтируется,
   и при следующем входе сборка начнётся заново. Это решение по умолчанию.
4. **Высота.** В `mixer.css`:
   - `.mixer-links { gap: 0 12px }` (было 16) — три ссылки шага штриха встают в одну
     строку на 375 px при любой высоте;
   - в блок `@media (max-height: 740px)`: `.mixer-swipe { gap: 6px; padding-top: 6px;
     padding-bottom: 6px }`. В мокапе правило лежит под `[data-compact]`, в реализации — без него.

   Кольцо 64 px и отдельная компактная реплика из первой версии больше не нужны.
5. **Реплика мастера** (`MasterLine`, появится с текстами #128) — по канону:
   - плоский аватар 28 px без радиального градиента;
   - без caps-подписи «МАСТЕР», для читалки остаётся скрытое «Мастер:».

   Решать в #350 или в #128 — на выбор владельца.
6. **«Покажите мастеру».** Вариант выбирает владелец, см. ниже.
7. **Smoke.** Тест #293 в `tests/smoke/tests/aroma-smoke.spec.ts` проверяет, что «Назад»
   уводит с экрана. Его надо переписать: «Назад» на акценте ведёт к основе, на основе —
   на прошлый экран. Плюс проверка, что панель видна и «Миксер» в ней активен.

## Проверка высоты (375×667)

Замер Playwright (Chromium) после загрузки шрифтов, вёрстка по канону #348. Колоде
положено ≥ 200 px.

| Экран | Без панели | С панелью, нынешние отступы | С панелью и уплотнением |
|---|---|---|---|
| Основа, реплики нет (так будет сразу после выкатки) | 327 px | 262 px | 278 px |
| Штрих, реплики нет | — | 262 px¹ | 278 px |
| Основа + двухстрочная реплика (#128) | — | 200 px, обрезан 1 px | 217 px |
| Штрих + двухстрочная реплика | 264 px¹ | 200 px, обрезан 1 px¹ | 217 px |

¹ С просветом ссылок 12 px. При нынешних 16 px ссылки штриха уходят во вторую строку,
и с репликой низ обрезан на 28 px.

- Без реплики мастера колода, «Беру/Дальше», ссылки и чаша помещаются с панелью и без
  уплотнения.
- Канон сделал экран ниже. Нет второй подсказки у пустой чаши, счётчик полок помещается
  в одну строку. Двухстрочная реплика теперь не влезает всего на 1 px, а не на 29–43 px,
  как в первой версии.
- С уплотнением в худшем случае колоде остаётся 217 px.
- На 375×812 колода 375 px, уплотнение там не включается.
- 375×667 по высоте близко к iPhone 12–15 в Safari с панелями браузера (≈ 390×664).

**Край вне scope — iPhone SE в Safari (375×548).** Без панели колода 208 px, всё
помещается. С панелью и уплотнением низ обрезан на 41 px. Нужна отдельная задача на
очень низкие экраны.

## «Покажите мастеру»: вариант на решение

| id | Панель | За | Против |
|---|---|---|---|
| `master-nav-*` (А) | видна, активен «Миксер» | из карточки сразу в любой раздел | экран для мастера отвлекает; расходится с карточкой микса из каталога |
| `master-full-*` (Б) | нет, как сейчас | одинаково с «Покажите мастеру» после каталога; фокус на составе | выход только через «Готово» |

**Рекомендуем Б.** Карточку снова открывает иконка «Карточка для мастера» в шапке (#289),
«Готово» ведёт туда, откуда гость пришёл. На 375×667 оба варианта помещаются без прокрутки.

## Что не реализовывать

- Подсветка стрелки «Назад», метки высоты, `[data-compact]` и доска нужны только для
  согласования.
- Правки G3 из блока мокапа делает #361, а не #350.
- Колода, тексты реплик (#128), события «Намиксуй» (#171) не меняются.
- Незаконченная чаша между визитами не сохраняется.
- Очень низкие экраны (375×548) — вне scope, см. выше.
