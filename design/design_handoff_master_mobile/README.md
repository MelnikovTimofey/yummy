# Handoff: мобильный Мастер (#540)

Мастер Nomad работает с телефона каждый день и чаще всего правит и создаёт миксы. Аудит `main` 2026-11-04:
«Дашборд» и «Полка» на телефоне уже удобные. Остальные разделы показывают десктоп в узком окне: таблицы
обрезаны, конструктор микса шире экрана, «Доступ» обрезан, повёрнутый телефон получает десктоп.
Баги аудита: #335, #337–#342. Мокап сделан по скиллу `atelier-feature-design`.

Статус: **ждёт согласования владельцем.**

## Как открыть

```bash
python3 -m http.server 8771 --bind 127.0.0.1
```

Затем `http://localhost:8771/design/design_handoff_master_mobile/mockups.html`.

- `mockups.html#shot=<id>` показывает один экран без доски: телефон 375×780, альбомная 812×375.
- `screens/` содержит снимки всех кадров (`<id>.png`, 2x).

## Файлы

- `mockups.html` — каркас телефона и классы `.m-*`, `.mb-*`.
- `board.jsx` — экраны на примитивах кита (`MasterTag`, `MasterToggle`, `FilterChip`) и доска.
- `data.js` — табаки, миксы, счета и рейлы полки Nomad, «сегодня» 4 ноября.

## Решения владельца (2026-11-04)

1. Главный сценарий с телефона — правка и создание миксов.
2. Таблицы на телефоне становятся карточками, как на «Полке».
3. Код смены крупно в листе «Ещё».
4. Повёрнутый телефон получает телефонную вёрстку, подсказки клавиш только при мыши.

## Экраны

| id | Экран | Что видно |
|---|---|---|
| `mixes` | Миксы | карточка: название, пропорции, состав, чем закрыт недостающий табак, статус, выборы и оценка; «Новый» в шапке |
| `mix-edit` | Микс, правка | одна колонка; назад вместо «Отмены»; сумма и «Сохранить» в нижней панели вместо меню разделов |
| `mix-edit-scrolled` | Микс, состав | полоса пропорций, пресеты, «Поровну», степпер у каждого табака, «Добавить табак» |
| `mix-library` | Добавить табак | библиотека в листе снизу: поиск, «Только в наличии», сортировка, «в составе» |
| `mix-new` | Новый микс | пустой состав, «Создать» неактивна до 100 % |
| `mix-warn` | Сумма 110 % | сумма жёлтая, «Сохранить» неактивна; табак без замены красным |
| `catalog` | Каталог | карточка табака: бренд и линейка, вкусы, место на полке, миксы; «На полку» сразу |
| `catalog-select` | Каталог, выбор | чекбоксы в карточках, действия в панели снизу, как на «Полке» |
| `deliveries` | Поставки | «Загрузить счёт» крупно, без зоны перетаскивания; карточка счёта |
| `delivery` | Счёт, черновик | строки карточками: текст из PDF, табак, метка, «Пришло»; «Принять» в нижней панели |
| `rails` | Рейлы | тип и число миксов в подвале, описание и состав в две строки |
| `rail-stat` | Статистический рейл | метки под названием, панель на всю ширину |
| `rail-new` | Новый рейл | миксы добавляются кнопкой, без «из списка слева» |
| `more` | Ещё | код смены сверху листа, разделы плиткой |
| `access` | Доступ | код смены, бот, операторы и сотрудники карточками с действиями |
| `land-mixes` | Миксы, альбомная | телефонная вёрстка, карточки в две колонки, без подсказок клавиш |
| `land-mix-edit` | Микс, альбомная | название слева, состав справа |

## Что реализовать

- Граница телефона: портрет до 640 px и повёрнутый телефон (низкий экран с сенсором). Один запрос для CSS и `useIsPhone`.
- На телефоне один заголовок раздела, в шапке; крупный h1 скрыт как на «Полке».
- Все `input`, `select`, `textarea` на телефоне не мельче 16 px.
- Боковые панели на телефоне на всю ширину.
- Данные и API не меняются.

## Что не реализовывать

- Новые возможности конструктора, фото бумажного счёта, свайпы, офлайн, отдельную вёрстку планшета.
- «Дашборд» и «Полку»: они уже готовы.
