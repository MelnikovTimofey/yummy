# Handoff: «рилсы» миксов (#153)

Мокап сделан по скиллу `atelier-feature-design`. «Рилсы» — отдельный раздел нижней панели гостя, как Reels в Instagram: миксы листаются полноэкранной вертикальной лентой. Фон каждого рилса — сцена, сгенерированная по вкусам микса: мятный дышит холодом, цветочный раскрывается лепестками. Бриф, решения владельца и ответы клиента — в [issue #153](https://github.com/MelnikovTimofey/yummy/issues/153).

## Решения владельца (2026-10-20)

- Стиль сцен — **B · Образ**: тонкие линейные мотивы. A · Атмосфера отвергнут: местами читался как цветное пятно.
- Вход — **полоса превью над Подбором** и **отдельный раздел «Рилсы» в нижней панели**. Ссылка «Смотреть лентой» отвергнута.
- Лента проработана для **вошедшего гостя**.
- Источник выбора («из рилсов» / «из карточки») в аналитике не различаем. Переход между рилсами только свайпом. Рейтинг показываем.

## Как открыть

`board.jsx` подгружается по XHR, поэтому нужен статический сервер из корня репо:

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

Затем открыть `http://localhost:8765/design/design_handoff_reels/mockups.html`.

- Доска — кликабельный прототип:
  - лента листается колесом, тачпадом или свайпом внутри телефона;
  - тап по сцене ставит паузу;
  - работают нижняя панель, полоса превью и сердечко;
  - «Подробнее» открывает карточку, «Покурить» — «Покажите мастеру».

  Переключатель «Стиль сцен» оставлен для истории решения.
- `mockups.html#shot=<id>` — один телефон 375×780 без доски, `&style=A` — отвергнутый стиль. Доступные `id`:
  - вход: `entry-b`, `entry-a` (отвергнут);
  - раздел: `reels-first`, `reel-bloom`, `reel-long`, `reel-norating`, `reel-paused`;
  - края: `reel-sheet`, `reel-confirm`, `reel-gone`, `reel-empty`, `reel-anon-heart`;
  - вошедший гость: `li-strip`, `li-bubble`, `li-taste`, `li-again`, `li-history`.

  Смена одного хэша страницу не перезагружает — для другого кадра поменяйте query (`?n=2#shot=…`).
- `screens/` — снимки Playwright. Секции доски: `scenes.png`, `rule.png`. Кадры:
  - `entry-b`, `reels-first`, `reel-long`, `reel-sheet`, `reel-gone`, `reel-empty`, `reel-anon-heart`;
  - вошедший гость: `li-strip`, `li-bubble`, `li-taste`, `li-again`, `li-history`.

## Файлы

- `mockups.html` — оболочка. Экранные классы и классы доски скопированы из `design_handoff_guest_cabinet`. Новые (`.reel*`, `.scene`, `.p`, `.m-*`, `.nav-6`) лежат в конце блока `<style>`.
- `board.jsx`:
  - правило выбора сцены (`pickScene`), сцены (`Scene`);
  - раздел (`Feed`, `Reel`), полоса превью (`EntryStrip`);
  - лента вошедшего гостя (`loggedItems`), карточка «Из рилсов», доска.

  Подбор и «Покажите мастеру» взяты из гостевого UI-кита без изменений.
- Данные — витрина прода на 2026-10-15 из `../design_handoff_showcase_compact/showcase-data.js`. Условности:
  - оценок гостей в снапшоте нет, поэтому шести миксам даны условные оценки, чтобы показать «★» (`RATED`);
  - набор «Для вас», причины, история и избранное вошедшего гостя — те же, что в мокапе кабинета `design_handoff_guest_cabinet`.

## Сцены здесь — приближение

В мокапе сцены сделаны на CSS-анимациях. В приложении каждая сцена — композиция Remotion: `useCurrentFrame` + `interpolate`, шум — `random(seed)` с `seed = mix.id`. Композиции играет `@remotion/player` прямо на телефоне гостя. Видеофайлов, хранилища и рендера на сервере нет. Нужно повторить характер движения, а не CSS один в один.

## Что реализовать

1. **Нижняя панель на шесть пунктов**:
   - «Рилсы» — третьим: Подбор · Витрина · **Рилсы** · Каталог · Миксер · Кабинет;
   - Lucide `Clapperboard` 24 px, название в `aria-label`;
   - поля панели 4 px, колонка ≈ 61 px — тап-зона больше 44 px.
2. **Полоса превью над Подбором** (`entry-b`):
   - кружки 60 px со статичным кадром сцены (`<Thumbnail>`), под каждым название в две строки 10,5 px;
   - рамка — hairline и тонкое кольцо `--accent-border`;
   - первые восемь миксов ленты в её порядке; нажатие открывает раздел «Рилсы» с этого микса.
3. **Раздел «Рилсы»** (`reels-first`):
   - лента на всю высоту над панелью, шапки «Арома Ателье» нет, панель остаётся видна, как в Instagram;
   - сверху слева — «Рилсы» (Literata 22 px), справа — счётчик `05 · из 33`, капсы 11 px;
   - вертикальный свайп со снапом: один жест — один рилс, автоперехода нет;
   - нажатие на «Рилсы» в панели открывает ленту с начала.
4. **Порядок ленты**:
   - гость без входа или вошедший с меньше чем тремя выборами — подбор по онбордингу, затем остальные доступные миксы `GET /guest/catalog/mixes`, без повторов;
   - не прошёл онбординг — лента начинается с каталога;
   - вошедший гость — см. «Вошедший гость».
5. **Рилс**:
   - фон — сцена на весь экран;
   - поверх — док с fade снизу:
     - надпись `.aroma-caps`: до трёх профилей, у вошедшего гостя — слот «Для вас»;
     - название — Literata 28 px, до трёх строк, целиком;
     - справа от названия — сердечко (как в карточке микса, #151);
     - `RatingPill` с числом оценок — только если гости оценивали (#185);
     - вкусы через `·`;
     - состав `CompositionStack` без полосы;
     - «Подробнее» (ghost) и «Покурить» (`AromaCTA` с `pulse`);
   - текст — HTML-слой, не часть композиции: читается скринридером и не дёргается при паузе;
   - появление дока — 240 мс: opacity и сдвиг на 6 px, ступенькой 60 мс. Сцена — бесшовный цикл ≈ 6 с.
6. **Подсказка** «Листайте вверх» с `chevron-up` — только на первом рилсе, пока гость не листнул.
7. **Пауза** — тап по сцене (кнопка на всю сцену, `aria-label` «Пауза» / «Продолжить»). В паузе по центру круг 56 px с `play`.
8. **Производительность**:
   - играет только активный рилс, соседи — статичный кадр, дальше — пустые слоты той же высоты;
   - Remotion грузится отдельным чанком при первом открытии раздела или полосы;
   - `prefers-reduced-motion` — статичный кадр, без появления дока.
9. **«Подробнее»** — карточка микса с надзаголовком «Из рилсов», сердечком и кнопкой «К рилсам». Оценка — как обычно.
10. **«Покурить»** — тот же `POST /guest/events/smoke-cta` и тот же экран «Покажите мастеру». «Готово» возвращает на тот же рилс.
11. **Сердечко без входа** (`reel-anon-heart`) — шторка «Избранное живёт в кабинете» с «Не сейчас» и «Войти», как в карточке микса (#151).
12. **Микс закончился** (`reel-gone`):
    - `smoke-cta` ответил 404;
    - строка-статус над кнопками: «Этот микс сейчас недоступен по наличию. Листайте дальше — остальные на месте.»;
    - CTA неактивна, лента не перескакивает.
13. **Пусто** (`reel-empty`): знак «Дым», «Сейчас показать нечего», «Ни одного микса в наличии. Мастер уже в курсе — спросите его, что будет сегодня.», «К подбору». Панель на месте.

## Вошедший гость

Лента начинается с «Для вас» (PRD §6.5). Набор, правила и причины — те же, что на Подборе, отдельной логики для рилсов нет. После блока «Для вас» идут остальные доступные миксы.

1. **Блок «Для вас»** (`li-taste`):
   - порядок: «Новое в вашем вкусе» (герой и ещё три) → «Шаг в сторону» → «Снова» (один повтор, последним);
   - над названием — надпись слота вместо профилей;
   - под названием — причина одной фразой (`--text-0`, 13,5 px): «Черника и холодок — рядом с вашими любимыми».
2. **Пузырь** (`li-bubble`) — четыре из пяти последних выборов — один микс или один ведущий профиль:
   - первым идёт «Шаг в сторону»;
   - над ним — та же подсказка, что на «Для вас»: «Давно на одном вкусе» и «Четыре из пяти последних — «Морозная ягода». Мастер уважает постоянство, но рядом есть кое-что.»;
   - ничего не запрещаем и не прячем.
3. **«Снова»** (`li-again`) — причина «Ваша оценка ★ 5 · выбирали 5 раз».
4. **После «Для вас»** (`li-history`):
   - рилсы без слота и причины;
   - если гость уже выбирал микс — рядом с рейтингом «Выбирали 1 раз · ваша ★ 4».
5. **Полоса на Подборе** (`li-strip`) — в порядке ленты, то есть «Для вас».
6. **Сердечко** — добавляет в избранное кабинета и убирает из него; «Покурить» пишется в историю.
7. **Меньше трёх выборов** — лента как у гостя без входа; сердечко и история работают.

Лента вошедшего гостя берёт данные из API кабинета (срезы #238–#245): «Для вас» с причинами, история, избранное. Своих эндпоинтов у рилсов нет.

## Правило выбора сцены

Профили у миксов прода раздуты (4–8 штук) и не упорядочены по силе: у «Морозной ягоды» первым идёт «Цветочно-травяной». Поэтому сцена берётся из `flavors`:

1. Каждый вкус относится к одному из шести мотивов по словарю (`MOTIFS` в `board.jsx`): **Холод**, **Цветы и травы**, **Сок**, **Ягоды**, **Тепло**, **Дым**.
2. Побеждает мотив с бо́льшим числом вкусов, при равенстве — тот, чей вкус идёт в списке раньше. **Холод перебивает всё** — самое яркое ощущение, и это пример клиента.
3. Второй по счёту мотив добавляет треть фигур своего цвета.
4. Ни один вкус не узнан — общая сцена в цвете первого профиля; профилей нет — она же в запасном цвете (решение владельца 2026-10-20, вместо «сцены по первому профилю»).
5. Цвет сцены — из `PROFILE_COLORS`:
   - «Сок» — «Цитрусовый», если есть цитрус, иначе «Фруктовый»;
   - «Тепло» — «Пряный», если пряностей не меньше половины, иначе «Десертный».

Таблица на доске (`rule.png`) считается тем же кодом, что и сцены. В приложении правило — чистая функция в `apps/aroma-web/src/lib/` с unit-тестами на примерах из таблицы. Словарь пополняется по мере появления новых вкусов в каталоге. Неузнанный вкус не ломает сцену — она падает на общую.

## Мотивы стиля B

Все фигуры — штрих 1,2–1,4 в цвете профиля, без заливки, как знак «Дым».

| Мотив | Фигуры | Движение |
|---|---|---|
| Холод | снежинки; иней по краям экрана | снежинки медленно падают с лёгким покачиванием и поворотом, иней дышит |
| Цветы и травы | цветок из пяти лепестков; мелкие лепестки | цветок раскрывается и медленно вращается, лепестки плывут вверх |
| Сок | кольцо; дольки | кольцо медленно вращается, дольки поднимаются |
| Ягоды | грозди из трёх ягод | медленно падают |
| Тепло | короткие искры; свечение снизу | искры поднимаются и мерцают |
| Дым | струи — S-кривые | прорисовываются снизу вверх и тают |
| Общая | тонкие кольца | поднимаются, расходятся и тают; только когда ни один вкус не узнан |

## Исключение из дизайн-системы

VISUAL FOUNDATIONS запрещает иллюстрации и выразительную анимацию: «Фотографий нет вообще… Никаких паттернов, текстур, шума и иллюстраций»; bounce и параллакс не используются. Рилсы — сознательное исключение, только для этого раздела:

- линейные мотивы стиля B;
- анимированный фон на весь экран.

Остальные правила действуют и здесь: один акцент — только заливка CTA и метки, цвета профилей — слой данных, без bounce, spring и параллакса. При реализации исключение записывается в `aroma-atelier-design/readme.md` (VISUAL FOUNDATIONS → «Анимация»), а рилс и полоса — в гостевой кит.

## Что не реализовывать

- Ссылка «Смотреть лентой» (`entry-a`) и стиль A — отвергнуты, на доске для истории решения.
- Переключатель стиля на доске — только для согласования.
- Условные оценки из `RATED` — в приложении рейтинг берётся из данных.
- Отметка «просмотрено» на кружках полосы, как у Stories, — не делаем: нужно хранить просмотры.
- Экспорт MP4 для соцсетей — возможный второй этап (`@remotion/renderer` из тех же композиций), в пилот не входит.
- Звук, лайки со счётчиками, комментарии. Сердечко — это личное избранное кабинета, а не соцмеханика.
- Подбор «Для вас» на доске — заглушка, экран как в мокапе кабинета.
