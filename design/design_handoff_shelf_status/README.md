# Handoff: Полка без граммов (#518)

Пожелание клиента (Nomad, 2026-11-04): граммовка каждого табака избыточна, инвентаризацию точка делает
взвешиванием премиального и обычного табака целиком. На полке остаётся статус «Закончился», по нему
собирается заявка. Мокап сделан по скиллу `atelier-feature-design`.

Статус: **ждёт согласования владельцем.**

## Как открыть

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

Затем `http://localhost:8765/design/design_handoff_shelf_status/mockups.html`.

- Доска: сверху кликабельный прототип (переключатель «Полка, К заказу», карточка по клику на строку,
  «Закончился» с тостом), ниже экраны и края.
- `mockups.html#shot=<id>` показывает один экран без доски: десктоп 1280×800, телефон 375×780.
- `screens/` содержит снимки всех кадров (`<id>.png`).

## Файлы

- `mockups.html` — оболочка «Мастера» и классы `.ss-*`.
- `board.jsx` — экраны на примитивах кита «Мастера» и доска.
- `data.js` — табаки полки Nomad, «сегодня» 4 ноября.

## Решения владельца (2026-11-04)

1. **В «Закупке» остаётся только список**: табаки «Закончился» с отметкой «держим постоянно». Сумм,
   бюджета, расхода и прогноза нет.
2. **Счета продолжаем загружать.** Принятый счёт возвращает пришедшие табаки в наличие.
3. **Вес в Мастер не вносится.** Взвешивание точка ведёт у себя.
4. **Закончился без «держим постоянно»** в заявку не попадает, только пропадает у гостя.

## Что уходит

- Остаток в граммах, отметки долей ¾ ½ ⅓ ¼, «Сколько осталось?», расход, «Хватит до», прогноз,
  статусы «Заканчивается» и «Проверьте остаток».
- Вид «Закупка» целиком (#327–#331) и бюджет (#326). Настройки полки (порция, срок поставки, бюджет)
  больше не нужны, шестерёнки нет.
- На Дашборде блоки «Прогноз расхода», «Деньги», «Расход по неделям». Новый Дашборд — #520,
  `design/design_handoff_guest_analytics/`.
- В «Поставках» граммы в строке счёта больше не правятся: приход отмечает табак как «Есть».
- #325 (интервал поставок) теряет смысл.

## Что остаётся без изменений

Отметка «проба» и «Зашло / Не зашло», стоп для гостей, аналоги (#475), «Добавить из каталога»,
загрузка и разбор счетов, выделение и действия пачкой (#517).

## Реализовать

- Статус полки: есть, закончился (с датой), стоп, в плане. «Закончился» снимает табак с витрины,
  миксы закрываются аналогом с полки, если он задан (инвариант 3).
- «К заказу» = закончился и `keepStocked`. Поставщик группы — по последнему принятому приходу.
- Принятый счёт ставит пришедшим табакам «Есть».
- Схема — отдельным первым срезом на human review: что делать с историей `StockEntry` (оставить как
  журнал приходов или удалить), `ShelfSettings.bowlGrams`, `leadDays`, `budgetKop`.
