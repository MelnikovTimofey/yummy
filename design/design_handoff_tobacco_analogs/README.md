# Handoff: аналоги табаков (#475)

Мокап сделан по скиллу `atelier-feature-design`. Правила в `PRD.md` §6.2 п.1 и §9.3 п.6 (#476).

Если у микса закончился один табак, а мастер задал ему аналог, который есть на полке, микс остаётся у гостя с заменой. Миксы и табаки взяты из сверки миксов мастера Nomad с полкой прода (2026-10-31).

Статус: **на согласовании у владельца.**

## Как открыть

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

Откройте `http://localhost:8765/design/design_handoff_tobacco_analogs/mockups.html`.
По адресу `mockups.html#shot=<id>` открывается один экран. Снимки лежат в `screens/<id>.png`.

| id | экран |
|---|---|
| `mixes` | Мастер, «Миксы»: статусы «с заменой» и «блокирован» с причиной |
| `shelf-analogs` | Мастер, карточка табака: аналоги заданы |
| `shelf-suggest` | Мастер, карточка табака: аналогов нет, похожие на полке |
| `sheet-sub` | Гость, карточка микса с заменой |
| `confirm-sub` | Гость, «Покажите мастеру» |
| `cab-fav` | Гость, избранное |

## Что реализовать

### Мастер, «Миксы»

- Новый статус `FilterChip` «С заменой» с числом, между «Виден гостю» и «Скрыт». Статусы не пересекаются: микс с заменой не входит в число «Виден гостю».
- В колонке «Статус»:
  - у микса с заменой — `MasterTag` «с заменой» (tone `info`), под ним «Lemon Shock вместо Lemonblast»;
  - у блокированного — `MasterTag` «блокирован» (tone `warning`), под ним «Нет: Red Rush». Имя табака — ссылка, она открывает карточку этого табака с полки.
- В колонке «Состав» остаётся рецепт мастера, без подмены.

### Мастер, карточка табака (шторка полки)

Новые секции идут после «Остаток» и «Расход», перед «Историей».

- **Аналоги.** Нумерованный список: бренд, название, остаток или «закончился», кнопки ↑ ↓ ×.
  - Номер в списке — это порядок замены. Гостю ставим первый табак, который есть на полке.
  - Ниже поле «Добавить аналог» с поиском по полке и каталогу.
  - Если аналогов нет — строка «Аналогов нет.»
- **Похожие на полке.** 2–5 табаков с полки с наибольшим пересечением `flavors` и `flavorProfiles`. Только табаки, которые сейчас есть и ещё не входят в аналоги. Справа их вкусы и кнопка «Сделать аналогом».
  - Без аналогов и без похожих секция не показывается.
- **В миксах.** Миксы с этим табаком и их статус. У микса с заменой ниже видно, что чем заменено.
- **Аналогия симметрична.** Добавили Lemon Shock к Lemonblast — значит, и Lemonblast стал аналогом Lemon Shock. Это одна группа, и в карточке любого табака группы видны остальные.
- **Тост после «Сделать аналогом».** Первая строка — **Barberry** жирным, вторая — «Аналог Red Rush. «Виноградный космос» виден гостю с заменой.» Если микс так и остался блокированным, вторая строка — только «Аналог Red Rush.» Отмена — как у прочих действий полки.

### Гость

- **Карточка микса** и **«Покажите мастеру»**: в составе стоит табак с полки, под названием мелкая подпись «замена» (`--text-muted`, 11 px). Пропорция берётся из исходного компонента. Мастер собирает чашу по экрану «Покажите мастеру», поэтому пометка есть и там.
- **Строки миксов** (Подбор, Каталог, подборки, «Для вас», кабинет) не меняются: пометки о замене в строке нет.
- **Кабинет.** Микс с заменой доступен, «Покурить» работает. «Сейчас нет: X» остаётся только у миксов, которые не собрать и с заменой.

## Что не меняется

- Дашборд и инвентарь считают микс с заменой доступным, а не блокированным. Отдельного экрана для этого нет.
- «Миксер» по-прежнему требует, чтобы все табаки были в наличии.
- Список «Блокировки» дашборда устроен как раньше. Ссылки «Нет: X» там тоже ведут в карточку табака.

## Вопросы владельцу

1. **Имя группы.** В мокапе у группы нет имени: группа — это просто список аналогов в карточке табака. Предлагаю без имени: на одно поле и одно действие меньше.
2. **«С заменой» — отдельный статус.** Можно было бы считать такие миксы частью «Виден гостю» с пометкой. Отдельный чип даёт мастеру одним нажатием увидеть, где сейчас подмена.
3. **Пометка у гостя — «замена».** Без указания, что именно заменено: гостю название исходного табака ничего не скажет.
