# Handoff: рилс без дока (#314)

Мокап сделан по скиллу `atelier-feature-design`. Переработка рилса из [#153](https://github.com/MelnikovTimofey/yummy/issues/153) (handoff `../design_handoff_reels/`). Бриф — в [issue #314](https://github.com/MelnikovTimofey/yummy/issues/314).

Сейчас вся информация о миксе — плотный док на нижней половине рилса, и сцена видна только сверху. Но сцена — абстрактный фон, а не видео: перекрывать её не страшно. Поэтому главное — название и описание — переезжает в центр. Внизу остаются рейтинг, сердечко, полоса состава и кнопки.

## Решение владельца (2026-10-21)

Выбран **A · Афиша с описанием**. Вкусы капсами вместо описания — только запасной путь для миксов, у которых описания нет (`a-nodesc`, `a-bare`).

Отвергнуты:
- **C · История** (кадры `c-*` оставлены на доске для истории решения): ≈ 4 с рассказа (название, затем вкусы по одному) перед той же афишей.
- **B · Чаша** (на этапе вариантов): забивка сверху, секторы по пропорциям. Гостю важнее вкус, чем бренды табака, а сверху на все сцены легла бы новая композиция.
- **D · Минимум** (на этапе вариантов): подпись в две строки и шторка состава. Описание по-прежнему не используется.

## Как открыть

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

Сервер запускается из корня репо. Затем открыть `http://localhost:8765/design/design_handoff_reels_v2/mockups.html`.

- Доска — кликабельный прототип. Лента листается, тап по сцене ставит паузу. «Подробнее» открывает карточку, «Покурить» — «Покажите мастеру». Кадр «История · живая» играет историю с начала.
- `mockups.html#shot=<id>` — один телефон 375×780. Чтобы открыть другой кадр, поменяйте query (`?n=2#shot=…`).
  - A: `a-first`, `a-nodesc`, `a-long`, `a-long-nodesc`, `a-bare`, `a-paused`, `a-gone`, `a-li-bubble`, `a-li-taste`;
  - C: `c-live`, `c-1`, `c-2`, `c-3`, `c-3-nodesc`, `c-2-long`, `c-li-taste`.
- `screens/` — снимки Playwright тех же кадров (кроме `a-gone` и `c-live`: у них есть взаимодействие).

## Файлы

- `mockups.html` — оболочка из `../design_handoff_reels/` без изменений. Новые классы `.pv-*` (афиша), `.st-*` (история) и `.timeline*` (доска) лежат в конце блока `<style>`.
- `board.jsx` — сцены, правило выбора сцены, данные ленты, карточка микса и сердечко без входа. Всё это скопировано из `../design_handoff_reels/board.jsx` без изменений. Новое — `PosterCenter`, `CompositionBar`, `FlavorBeat`, `Progress`, `Reel`, доска.

## Что реализовать

### A · Афиша

1. **Центр** (по вертикали — свободное место между верхом и нижним блоком):
   - надпись слота «Для вас» капсами — только у вошедшего гостя;
   - название — Literata 34 px, до трёх строк, по центру;
   - описание — Literata italic 18 px, `--text-0`, ширина до 28ch. Без описания на его месте вкусы капсами 12 px через `·`; точка не переносится отдельно от слова;
   - причина «Для вас» — 13,5 px, `--text-1`;
   - под текстом — мягкое радиальное затемнение, без плашки.
2. **Профили и строка вкусов** при наличии описания не показываются.
3. **Низ** — fade снизу, без дока:
   - строка: рейтинг `RatingPill` слева (без оценок его нет), сердечко справа;
   - полоса состава 6 px, ramp `--composition-*`;
   - под полосой состав в две колонки: производитель капсами, название табака до двух строк, доля. Один табак — одна колонка;
   - «Подробнее» и «Покурить».
4. **Подсказка «Давно на одном вкусе»** поднимается в верх рилса: центр занят афишей.
5. **Края:**
   - «Листайте вверх» — над нижним блоком;
   - «недоступен по наличию» — строка-статус вместо состава;
   - пауза — как сейчас. Текстовый слой не перехватывает тапы, тап по тексту тоже ставит паузу.
6. **Появление при активации рилса:** центр, затем детали; полоса состава прорисовывается слева направо. При `prefers-reduced-motion` — без анимации.

### C · История — отвергнут, не реализовывать

Описание оставлено для истории решения. Финальный кадр — ровно афиша A. Перед ним два такта, прогресс — три сегмента 2 px сверху.

1. **0–1,8 с — название.** Literata 40 px по центру. Соседний рилс при свайпе показывает этот же кадр статично.
2. **1,8–4,2 с — вкусы.**
   - Сверху название 20 px.
   - Ниже вкусы по одному, раз в 0,45 с, Literata 30 px, поочерёдно справа и слева. У каждого вкуса — фигура его мотива из сцены (`kit.tsx`) цветом профиля мотива. Неузнанный вкус идёт без фигуры.
   - Больше четырёх вкусов — четыре и «и ещё N».
3. **С 4,2 с — финал.** Афиша A с анимацией появления, держится до свайпа.
4. **Кнопки и сердечко видны с первой секунды:** выбирать можно, не дожидаясь финала. Рейтинг и состав появляются в финале.
5. **Тап — пауза** сцены и истории. Свайп назад запускает историю заново.
6. **Сразу финал:** в полосе над Подбором, при `prefers-reduced-motion` и при статичном кадре до загрузки Remotion.
7. **Где живут такты.** В приложении такты — часть композиции Remotion (`useCurrentFrame`): текст рисуется поверх сцены в том же плеере, длительность композиции ≥ 6 с, финал держится. Альтернатива — HTML-слой с таймером от `Player`. Выбрать при нарезке.

## Что не меняется

- Полоса рилсов над Подбором (кружки), порядок ленты, правило выбора сцены, сами сцены.
- Карточка «Подробнее», «Покажите мастеру», слайд в конце ленты, пустая лента.
- Backend и контракт: `description` уже приходит в гостевом каталоге. Нагрузка — нет.
