# Handoff: автор микса (#491)

Мокап сделан по скиллу `atelier-feature-design`. Автор — сотрудник, который завёл микс.
Виден только в Мастере, гость автора не видит.

Статус: **ждёт согласования владельцем**.

## Как открыть

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

Затем откройте `http://localhost:8765/design/design_handoff_mix_author/mockups.html`.
`mockups.html#shot=<id>` показывает один экран. Снимки лежат в `screens/<id>.png`.

| id | экран |
|---|---|
| `mixes` | «Миксы»: колонка «Автор» и атрибут «Автор» |
| `mixes-author` | открыт список «Автор» |
| `mixes-filtered` | выбран автор |
| `builder` | шапка конструктора существующего микса |

## Что реализовать

- **«Миксы»:**
  - колонка «Автор» после «Статуса», в ней имя учётки сотрудника (`StaffAccount.name`). Нет автора — прочерк;
  - атрибут «Автор» в конце ряда фильтров, тот же компонент, что у прочих атрибутов (#464);
  - в списке только сотрудники, у которых есть миксы;
  - одно выбранное значение — на чипе имя, несколько — «Автор: N».
- **Конструктор:** в шапке существующего микса после числа компонентов «· автор Максим (Мастер)». У нового микса автора нет.
- **Кто автор:**
  - новый микс — тот, кто сохранил;
  - копия — тот, кто скопировал;
  - правка автора не меняет.

## Что не меняется

- Гостевой продукт.
- Статусы, колонки «Состав», «Выборы», «Рейтинг».
- Мобильная вёрстка «Миксов»: колонка и атрибут работают так же, как прочие.

## Данные в мокапе

Миксы до мастера — с прода, автор «Ателье Admin». Миксы Максима — из сверки миксов мастера с полкой прода 2026-10-31, с аналогами из колонки «Замена с полки».
