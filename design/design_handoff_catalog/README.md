# Handoff: Каталог гостя — поиск и фильтры в одном месте (#181)

Мокап сделан по скиллу `atelier-feature-design`. Сейчас выдачу Каталога `apps/aroma-web`
настраивают в трёх местах: поле, лента профилей и поповер со вкусами и сортировкой. Оба варианта
собирают всё у поля поиска и делают список плотнее. Бриф и критерии приёмки —
в [issue #181](https://github.com/MelnikovTimofey/yummy/issues/181).

Решения владельца, которые мокап уже учитывает (2026-10-16):
- сортировки нет, порядок по алфавиту;
- «★» только у миксов с оценками (#185);
- характеры (профили) показываются как есть, без обходов до исправления данных в #182.

## Как открыть

`board.jsx` подгружается по XHR, поэтому нужен статический сервер из корня репо:

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

Затем открыть `http://localhost:8765/design/design_handoff_catalog/mockups.html`.

- Доска — кликабельный прототип: переключатель «A · всё в поле», «B · поле и шторка», «Сейчас».
  Ниже — экраны для сравнения и края.
- `mockups.html#shot=<id>` — один телефон 375×780 без доски, для скриншотов в issue и PR.
  Доступные `id`:
  - Сейчас: `now`, `now-hidden`;
  - A: `a`, `a-focus`, `a-typing`, `a-tokens`;
  - B: `b`, `b-sheet`, `b-tokens`;
  - края: `edge-empty`, `edge-many`, `edge-keyboard`, `edge-long`.
- `screens/` — снимки секций доски: `now.png`, `variant-a.png`, `variant-b.png`, `edges.png`.

## Файлы

  (`GET /guest/onboarding/options`) в формате `mock-data.js` кита, плюс `ratingsCount` и `popularity`.

## Варианты

Решение владельца — **ждём**.

| Что | Вариант | Как выглядит |
|---|---|---|
| Где живут фильтры | **A · всё в поле** (`a`) | Одно поле «Вкус, характер, табак или название». Фокус открывает панель подсказок прямо под полем: частые вкусы, характер, табак, у каждого счётчик миксов. При вводе подсказки фильтруются по вхождению и делятся по типам. Касание превращает подсказку в метку, текст очищается, панель остаётся открытой. Кнопок рядом с полем нет. |
| | **B · поле и шторка** (`b`) | Поле «Название, вкус или табак» и кнопка «Фильтры» со счётчиком выбранного. Кнопка открывает шторку, как у карточки микса: характер и вкусы со счётчиками, частые вкусы первыми, поиск по вкусам, «Все 75 вкусов». Кнопка внизу показывает, сколько миксов найдётся. Табак ищется только текстом в поле. |

Что видно на 375×780 в покое (тонкая шапка, нижняя панель, клавиатура закрыта):
- сейчас — 7 строк, рейл фильтров 100 px;
- A и B — 9 строк, рейл 67 px (с метками — 106 px).

## Что реализовать в любом варианте

1. **Поле поиска** — 44 px, шрифт 16 px (иначе iPhone увеличивает страницу при фокусе),
   `aria-label` «Поиск по каталогу».
2. **Ленту профилей и поповер с сортировкой убрать.** Сортировки нет: порядок по алфавиту
   (`localeCompare(…, 'ru')`).
3. **Метки выбранного** — под полем, одной строкой с горизонтальной прокруткой, шапка не растёт:
   - `Chip` активный, после текста `×`, точка профиля — только у характера;
   - `aria-label` «Убрать фильтр «…»» (у `Chip` в приложении есть `ariaLabel`);
   - касание снимает метку.
4. **«Найдено · N»** и «Сбросить» справа. При N = 0 «Сбросить» в этой строке не показывается,
   его заменяет пустое состояние.
5. **Строка микса** — как сейчас, но плотнее:
   - знак профиля 36 px, отступы 7×12 px, зазор между строками 6 px;
   - совпавшие с меткой или текстом вкусы — первыми в строке вкусов;
   - «★» — по #185. Пока #185 не влит, в Каталоге «★» остаётся как сейчас.
6. **Пустое состояние**: «По выбранным фильтрам ничего не найдено. Даже мастер развёл руками.»,
   под ним «Убрать «<последняя метка>»» (`aroma-ghost-sm`) и «Сбросить всё».
7. **Логика фильтра** не меняется: внутри типа — «или», между типами и с текстом — «и».
   Новый тип метки — табак: фильтр по `components[].manufacturer`.
8. **Счётчики** вкусов и характеров — `flavorCounts` и `profileCounts` из
   `/guest/onboarding/options`, они уже приходят. Счётчики табаков считаются на клиенте по каталогу.
   Контракт backend не меняется.

### Только A

- Панель подсказок живёт **внутри sticky-рейла** с `position: absolute` под полем. Урок #179:
  в потоке после рейла она уедет за экран при прокрутке.
- Фон непрозрачный (`--bg-raised` → `--bg-base`), иначе сквозь панель читается список.
  Нижняя строка «Показать N миксов» закреплена (`position: sticky`) и закрывает панель.
- Без ввода: 8 частых вкусов, все характеры, 8 табаков — по убыванию счётчика.
  С вводом: группы «Характер», «Вкус», «Табак», в каждой до 8 подсказок, уже выбранные не показываются.
- Высота панели — до верхней кромки клавиатуры (`visualViewport.height`), лишнее прокручивается.
- Касание строки микса закрывает панель.

### Только B

- Кнопка «Фильтры» — inline-SVG «три линии», текст «Фильтры» и число выбранного кремовым.
  Активная рамка — `--guest-chip-border-on`.
- Шторка — разметка и анимация карточки микса (`MixDetailModal`, свайп вниз закрывает).
  Выбор применяется сразу, CTA «Показать N миксов» закрывает шторку. При N = 0 CTA
  неактивен: «Ничего не найдено».
- Вкусы: первые 18 по счётчику, «Все 75 вкусов» раскрывает остальные, поиск по вкусам фильтрует список.

## Что не реализовывать

- Доска, переключатель и клавиатура-заглушка в крае `edge-keyboard` нужны только для согласования.
- Карточка микса, «Покажите мастеру», Подбор и Витрина не меняются.
- Качество совпадений поиска (ё, русские названия брендов, подписи профилей в тексте) — отдельный срез после основного.
- Группы списка по характеру — после #182.
