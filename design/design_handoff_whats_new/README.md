# Handoff: «Что нового» в «Мастере» (#226)

Мокап по скиллу `atelier-feature-design` и референсу владельца (окно «Что нового в 1.2.5»
со слайдами). Бриф — в [issue #226](https://github.com/MelnikovTimofey/yummy/issues/226).

Статус: **на согласовании владельцем.**

## Как открыть

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

`http://localhost:8765/design/design_handoff_whats_new/mockups.html` — доска, слайды кликабельны.
`mockups.html#shot=<id>`: `trigger`, `slide-1`, `slide-2`, `slide-list`, `read`, `phone-1`, `phone-list`.
Снимки — `screens/<id>.png`. Иллюстрации слайдов — снимки реализации из `design_handoff_inventory/screens/`.

## Что реализовать

1. **Данные** — `apps/master-web/src/lib/whats-new.ts`: массив выпусков, новый — первым.
   Выпуск: `id` (строка, уникальная), `label` («21 октября»), `slides[]`.
   Слайд: `title`, `text`, одно из `image` (+ необязательный `imagePhone`) или `list: string[]`,
   необязательный `action: { label, tab }` — «Открыть раздел». Картинки — в `apps/master-web/public/whats-new/<id>/`
   (WebP/JPEG, ширина ≤ 1440 px). Крупная фича при релизе добавляет свои слайды в новый выпуск.
2. **Кнопка в шапке** — «Что нового» между вкладками и «Поиск и команды»; точка-акцент (`--accent`
   с ореолом `--accent-soft`), пока `lastSeen !== releases[0].id`. Выпусков нет — кнопки нет.
   **Решение владельца (2026-10-20):** на ≤ 1480 px кнопка — точка + иконка `Sparkles` без подписи
   (подпись в `aria-label`/`title`), с 1481 px — с подписью: с седьмой вкладкой «Поставки» подпись на 1280 px не помещается.
3. **«Прочитано»** — `localStorage['atelier.whatsNew.seen.<login>'] = id`. Отмечается при закрытии окна
   (крестик, Esc, «Готово», клик по фону). Хранилище недоступно — точка горит, окно работает.
4. **Окно** (`#shot=slide-1`, `slide-list`): шапка «ЧТО НОВОГО · <label>» и крестик; иллюстрация в рамке
   (снимок — `cover`, от левого верхнего угла); заголовок (serif 26 px) и текст; низ — точки-страницы
   (кликабельны, активная — акцент), «Открыть раздел» (если есть `action`: закрывает окно и переключает вкладку),
   «Назад» (на первом — неактивна), «Далее» / «Готово» на последнем. ← → листают, Esc закрывает.
   Окно само не открывается.
5. **Телефон** (`#shot=phone-1`): окно на весь экран, `imagePhone`, если есть, иначе снимок фрагментом от
   левого верхнего угла; свайп влево/вправо листает; «Открыть раздел» не показывается. Кнопка «Что нового» —
   в шторке «Ещё» с той же точкой (и точка на пункте «Ещё» нижней навигации).
6. **Первый выпуск** — инвентарь (#152), 6 слайдов как на доске.

## Что не реализовывать

- Автопоказ при входе, редактор выпусков, хранение «прочитано» на сервере.
- Историю старых выпусков — показываем только последний (появится нужда — отдельный срез).
