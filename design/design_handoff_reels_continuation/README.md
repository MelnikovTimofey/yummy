# Handoff: рилсы после Подбора (#349)

Мокап по скиллу `atelier-feature-design`, бриф в [issue #349](https://github.com/MelnikovTimofey/yummy/issues/349).

Решения владельца 2026-10-23:
- рилсы — второй пункт панели;
- лента продолжает Подбор без повторов;
- полоса кружков над Подбором (#264) уходит;
- переход в ленту — тизер и дотягивание за край, назад — свайп вниз.

## Статус

**На согласовании.** Мокап перерисован под канон редизайна #348 (#358, `1cafc121`), согласуется заново. Владельцу нужно выбрать основной вариант или Б.

## Как открыть

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

Сервер запускается из корня репо. Адрес: `http://localhost:8765/design/design_handoff_reels_continuation/mockups.html`.

- Доска — живой прототип: колесо или мышь у нижнего края тянут за край, тап по тизеру открывает ленту. На первом рилсе колесо вверх или «К подбору» возвращают назад.
- `mockups.html#shot=<id>` — один телефон 375×780:
  - конец Подбора: `end-anon`, `end-li`, `end-anon-b`;
  - дотягивание: `pull-mid`, `pull-ready`;
  - лента: `cont-first`, `cont-first-li`, `back-pull`;
  - панель: `nav-recs`, `nav-reels`;
  - края: `empty-recs`, `empty-reels`, `small-end`, `small-reels`, `feed-empty`.
- `screens/` — снимки Playwright, `screens/overview.png` — ключевые кадры на одном листе.

## Что реализовать

### 1. Порядок ленты (`lib/reel-feed.ts`)

1. `reelEntries` исключает миксы, показанные на Подборе:
   - без входа и в cold — сначала рекомендации, не влезшие на Подбор, затем каталог;
   - в «Для вас» (personal) — каталог без миксов всех показанных слотов;
   - в «Под настроение» — без миксов этого режима.
2. Надписей слотов и причин в ленте нет.
3. `reelStrip` и `ReelStrip` удаляются.

На экране гостя без входа пять миксов, а не четыре, как в брифе: герой и четыре «Тоже подходят». Выдача — шесть, шестой открывает ленту (`cont-first`, «Mr. Pink»). Показанными считаются отрисованные миксы.

### 2. Конец Подбора

1. Подбор — как в срезе G1 (#359, #372). Тизер последним блоком:
   - без входа — под «Собрать свой микс» (`end-anon`);
   - в «Для вас» приглашения нет, тизер после «Снова» (`end-li`).
2. Вариант Б (`end-anon-b`): тизер вместо приглашения. Оно остаётся в конце ленты и в панели.
3. Тизер — одна кнопка: статичная стрелка вверх и «Ещё N миксов в рилсах», Literata 16 px. Без надписи над ним, без пульса и анимации. Мини-кадров сцен нет: исключение для сцен действует только в разделе «Рилсы».
4. Продолжение пустое (`small-end`): «Других миксов нет», дотягивание ведёт на конец ленты.
5. Подбор пуст (`empty-recs`): тизера и дотягивания нет. Текст пустого Подбора — по инвентаризации №25–26.

### 3. Дотягивание за край

1. Срабатывает только сверх края: порог — 120 px хода сверх края. Лента идёт за пальцем вдвое медленнее, снизу видна статичная сцена первого рилса.
2. Кольцо со стрелкой показывает ход до порога (`pull-mid`). На пороге оно заливается `--accent` (`pull-ready`). Подписей нет.
3. Отпустил после порога — лента. Раньше — Подбор возвращается на место, 240 мс.
4. Движение — только отклик на жест, бесконечной анимации нет. Инерция прокрутки до края порог не набирает. При `prefers-reduced-motion` возврат без анимации.

### 4. Лента и путь назад

1. Рилс — как в срезе G2 (#360): без строки профилей, «★» без числа оценок, «Листайте вверх» без анимации, CTA без пульса.
2. Из тизера и из панели — одна лента с тем же первым рилсом. Активный пункт панели — «Рилсы».
3. На первом рилсе сверху кнопка «К подбору», sentence case, радиус `--r-guest-control`, без иконки.
4. Свайп вниз на первом рилсе (`back-pull`) — зеркальное дотягивание с тем же порогом. Возврат — в конец Подбора, к тизеру.
5. Подбор пуст (`empty-reels`): лента — весь каталог, «К подбору» нет, свайп вниз ничего не делает.
6. Конец ленты (`small-reels`, №52): только кнопка «Собрать свой микс», та же, что в конце Подбора (`MixerInvite`). Заголовок «Это все миксы» убран по решению владельца.
7. Пустая лента (`feed-empty`, №51): «Миксов в наличии нет» и «Спросите мастера, что есть сегодня.».

### 5. Нижняя панель

Порядок: Подбор, Рилсы, Витрина, Каталог, Миксер, Кабинет. Меняется только порядок в `BottomNav.tsx`.

## Что не меняется

- Сцены рилсов, лист микса, «Покурить» — то же событие `smoke_cta_clicked`.
- Микс закончился, пока гость листал: как сейчас.
- Backend и контракт. Нагрузка — нет.

## Smoke

Пункты панели ищутся по имени, новый порядок их не ломает. Тест полосы кружков уходит. На его место — тест: Подбор, тизер, первый рилс не из Подбора, «К подбору».

«MUSTHAVE» капсом в составе — так производитель записан в данных прода.
