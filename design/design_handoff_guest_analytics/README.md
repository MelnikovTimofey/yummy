# Handoff: Дашборд, выборы гостей (#520)

Пожелание клиента (Nomad, 2026-11-04): аналитика выборов гостей с инфографикой по популярным табакам
и миксам, как идеи для заказа. Графики — shadcn charts, период — неделя, месяц, квартал, всё время,
произвольный. Мокап сделан по скиллу `atelier-feature-design`.

Статус: **согласован владельцем 2026-11-04.**

## Как открыть

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

Затем `http://localhost:8765/design/design_handoff_guest_analytics/mockups.html`.

- Доска: сверху кликабельный прототип с переключателем периода, ниже экраны и края.
- `mockups.html#shot=<id>` показывает один экран без доски: десктоп 1280×800, телефон 375×780.
- `screens/` содержит снимки всех кадров (`<id>.png`).

## Файлы

- `mockups.html` — оболочка «Мастера» и классы `.ga-*`.
- `board.jsx` — экран, графики на SVG по образцу shadcn charts, доска.
- `data.js` — выборы по дням за 30 дней, недели считаются из дней, «сегодня» 4 ноября.

## Решения владельца (2026-11-04)

1. **Периоды скользящие**: неделя — последние 7 дней, месяц — 30, квартал — 90; плюс всё время и свои даты.
2. **Табак засчитывается целиком** (+1) за каждый выбор микса, где он есть, без веса доли.
   При замене аналогом засчитывается табак с полки.
3. **Аналитика заменяет «Дашборд смены».** Сигналы для команды переезжают сюда.
4. **Графики**: выборы по дням, популярные табаки, популярные миксы, доли по вкусам.

## Экраны

| id | Экран | Что видно |
|---|---|---|
| `month` | Месяц | плитки: выборов, свои миксы, миксов выбирали, оценка; выборы по дням; топ табаков и миксов |
| `month-tip` | Подсказка | наведение на столбец: дата, миксы каталога и свои отдельно |
| `month-bottom` | Низ экрана | вкусы кольцом с долями; сигналы со ссылками в разделы |
| `quarter` | Квартал | больше 31 дня, столбцы по неделям |
| `calendar` | Даты | календарь на два месяца, диапазон, «Показать» |
| `mobile` | Телефон | период чипами, плитки 2×2, графики друг под другом, топ 5 табаков |
| `edge-few` | Мало данных | меньше 20 выборов: графиков нет, плитки и сигналы есть |
| `edge-empty` | Выборов нет | период без выборов |

## Графики → shadcn charts

| Блок | shadcn | Цвета |
|---|---|---|
| Выборы по дням / неделям | Bar Chart, stacked, `CartesianGrid vertical={false}`, `ChartTooltipContent` | миксы каталога `--chart-1`, свои `--chart-5` |
| Популярные табаки, миксы | Bar Chart, `layout="vertical"`, подпись внутри столбца (Custom Label) | нейтральная заливка `rgba(232,230,224,.10)`, метки «закончился», «скрыт у гостя» `--danger` контуром |
| Вкусы | Pie Chart, donut with text | `--profile-*` (слой данных) |

`ChartConfig` берёт цвета из токенов Film Noir, палитра shadcn по умолчанию не используется. Бордо — только
основной ряд динамики: двадцать бордовых столбцов в топах спорили бы с правилом одного акцента.

## Метки и сигналы

- У популярного табака: «закончился» (на полке «Закончился»), «проба». Это и есть идея для заказа.
- У популярного микса: «скрыт у гостя» (нет табака и аналога), «с аналогом», ★ оценка.
- Сигналы: закончились популярные табаки (→ «К заказу»), скрытые миксы (→ «Миксы»), пустые рейлы (→ «Рейлы»).

## Реализовать

- Один эндпоинт аналитики Мастера с `from`/`to`; агрегация в Postgres (`SmokeCtaEvent`,
  `CustomMixSmokeEvent.components`), не в Node. Нагрузка — малое: замер на продуктовом снапшоте.
- `SmokeCtaEvent` не хранит состав микса: табаки считаются по текущему составу.
- Меньше 20 выборов за период — «Мало данных», без графиков.
- Только агрегаты, без идентификаторов гостей (PRD §4).
- Smoke дашборда обновить в том же PR: меняются заголовок и разделы.
