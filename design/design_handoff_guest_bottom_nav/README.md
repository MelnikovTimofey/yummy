# Handoff: нижняя панель навигации гостя (#168)

Мокап по скиллу `atelier-feature-design`: гостевое меню `apps/aroma-web` переезжает
в панель со значками внизу экрана, как в Instagram. Бриф и критерии приёмки — в
[issue #168](https://github.com/MelnikovTimofey/yummy/issues/168).

## Как открыть

`board.jsx` подгружается по XHR, поэтому нужен статический сервер из корня репо:

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

Дальше открыть `http://localhost:8765/design/design_handoff_guest_bottom_nav/mockups.html`.

- Доска: кликабельный прототип с переключателями вариантов, четыре варианта панели и
  экраны в разных состояниях.
- `mockups.html#shot=<id>` — один телефон 375×780 без доски, для скриншотов в issue и
  PR. Доступные `id`: `a-line`, `b-line`, `a-dot`, `b-dot`, `showcase`, `catalog`, `rail`,
  `empty`, `mixer`.

## Файлы

- `mockups.html` — оболочка. Экранные классы скопированы из гостевого UI-кита
  (`.claude/skills/aroma-atelier-design/ui_kits/aroma-guest/index.html`); новые стили
  (`.topbar-thin`, `.bottom-nav`) лежат в конце блока `<style>`.
- `board.jsx` — новые `ThinTopbar` и `BottomNav`, видимость панели по экранам, доска.
  Экраны Подбора, Витрины, Каталога, подборки, карточки микса и «Покажите мастеру» берутся
  из UI-кита без изменений.

## Что реализовать

1. **Тонкая шапка** на Подборе, Витрине и Каталоге: знак «Дым» (высота 22 px) и
   «Арома Ателье» (Literata 19 px), справа иконка `KeyRound` 20 px с `aria-label="Сменить код"`.
   Иконка делает то же, что текущая кнопка «Сменить код». Строку «подбор миксов» и табы
   из шапки убрать.
2. **Нижняя панель** `BottomNav`: 4 пункта, иконки `lucide-react`:
   - Подбор — `Sparkles`;
   - Витрина — `GalleryHorizontalEnd`;
   - Каталог — `Search`;
   - Миксер — `Blend`.

   Внешний вид:
   - иконка 24 px, stroke 1.8, у активной — 2.1;
   - высота пункта 52 px (58 px с подписью), нижний отступ `--safe-bottom`;
   - фон `--guest-topbar-bg`, сверху линия `--line`.

   Цвета:
   - неактивный пункт — `--text-muted`;
   - активный — `--text-0` с меткой `--accent`, без заливки бордо (PRD §12);
   - метку и подписи выбирает владелец, см. «Варианты».

   Разметка: `<nav aria-label="Гостевая навигация">`, у активного пункта
   `aria-current="page"`. Без подписей у каждого пункта есть `aria-label`.
3. **Где видна панель:**
   - видна на Подборе, Витрине, Каталоге и в подборке (rail); в подборке активна «Витрина»;
   - не видна до доступа, на знакомстве, в онбординге, на «Покажите мастеру» и в Миксере.
4. **Миксер из панели:** открывается на весь экран. `MixerScreen` `onExit` возвращает на
   экран, откуда гость пришёл: `mixerReturnView` расширяется до каталога и подборки.
   Карточки-приглашения `MixerInvite` остаются.
5. **Раскладка:** панель — последний flex-элемент `.phone-shell`, а не `position: fixed`.
   Прокрутка `.content` заканчивается над панелью, последний элемент списка виден целиком.
6. «Карточка для мастера» остаётся закреплённой под шапкой, как сейчас.

## Варианты

Владелец выбрал **`a-line`** (2026-10-15). Остальные варианты оставлены в мокапе как
отвергнутые.

| id | Подписи | Метка активного | Решение |
|---|---|---|---|
| `a-line` | только значки | черта 22×2 px по верхней кромке | **выбран** |
| `b-line` | значок + подпись 9.5 px caps | черта | отвергнут |
| `a-dot` | только значки | точка 4 px под значком | отвергнут |
| `b-dot` | значок + подпись | точка | отвергнут |

В реализации подписей нет, поэтому `aria-label` у пунктов обязателен.

## Что не реализовывать

- Миксер в мокапе упрощён (`MixerMock`): проверяется только полноэкранный режим и
  возврат. Сам экран «Намиксуй» не меняется.
- Переключатели вариантов и доска — только для согласования.
- Жесты свайпа между табами, пятый пункт «Я» — вне scope (#168).

## Сопутствующие правки в срезе реализации

- `PRD.md` §8.8: вход в «Намиксуй» также из нижней панели.
- `aroma-atelier-design`: в `readme.md` (ICONOGRAPHY) и `guidelines/iconography.card.html`
  указано «активная иконка — `--accent`», а PRD §12 требует кремовую. Документацию
  привести к PRD и добавить `BottomNav` в гостевой кит.
- `tests/smoke/tests/aroma-smoke.spec.ts`: табы ищутся как
  `getByRole('button', { name: 'Витрина' })`. При варианте без подписей имя берётся из
  `aria-label`, поэтому локатор не меняется. Проверить на прогоне.
