# Арома Ателье — Design System

Дизайн-система продукта **«Арома Ателье»** — сервиса подбора кальянных миксов для заведения. Восстановлена из исходного кода продукта (см. «Источники»), не придумана заново: все токены, шрифтовые шкалы, отступы, радиусы и компоненты сняты с рабочих приложений.

## Контекст продукта

«Арома Ателье» — три связанных контура вокруг одного каталога табаков и миксов:

| Поверхность | Что это | Кто пользуется |
|---|---|---|
| **Арома Ателье** (`apps/aroma-web`) | Гостевой mobile-first web без обязательной авторизации (кабинет — по желанию, вход через Telegram): 18+ gate → ежедневный код → знакомство → онбординг по вкусам → подбор / витрина / каталог → карточка микса → `Покурить` → карточка для мастера | гость заведения, вход по QR |
| **Мастер** (`apps/master-web`) | Backoffice-консоль: инвентаризация табаков, менеджер миксов, менеджер рейлов, дашборд смены, доступ (код смены, Telegram-allowlist, staff-аккаунты, журнал) | кальянный мастер, администратор |
| **Telegram-бот** (`services/telegram-bot`) | Канал раздачи ежедневного кода персоналу (не гостевой интерфейс) | персонал |

Домен: `Tobacco` → `MixComponent` → `Mix` → `Rail`. Таксономия строго разделена на три поля: `flavorProfiles` (категории-«полки»), `flavors` (конкретные ноты), `flavorTags` (мета-теги: хит, новичкам, холодок). Гость проходит путь без регистрации; по желанию входит через Telegram в кабинет с историей выборов, избранным и подбором «Для вас»; ключевое продуктовое событие — нажатие `Покурить` (`smoke_cta_clicked`), из него считаются статистические рейлы и дашборды.

Общая визуальная база обоих веб-приложений — дизайн-система **Film Noir** (PRD §12): тёмные дымчатые поверхности, тёплый туманно-серый текст, **единственный** глубокий акцент-бордо `#8E2F3C`. Гость получает кинематографичную, «ламповую» подачу; Мастер — тот же палитрой, но плотнее и утилитарнее (control surface, не lounge UI).

## Где живут значения

Токены вынесены из скилла в пакет **`packages/design-tokens/`** — это единственное место, где заданы значения Film Noir. `tokens/*.css` здесь — тонкие реэкспорты из пакета; правка значения в них ничего не даст, менять нужно пакет.

Приложения получают канон не импортом (docker build context у каждого свой), а генератором `node packages/design-tokens/sync.mjs`, который перезаписывает коммитящиеся `apps/*/src/design-tokens.generated.css`. Расхождение ловит CI-чек `atelier-design-tokens`.

## CONTENT FUNDAMENTALS

**Язык — только русский** (инвариант PRD №1). Английский допустим лишь в именах табаков/брендов (`Darkside Wildberry`, `Cheesecake`) и в служебных ярлыках Мастера (`admin`, `master`, `/staff/audit/events`).

**Тон.** Спокойный и тёплый, без шуток. Заведение говорит с гостем как мастер зала, который знает своё дело: коротко, по делу, без сервисной услужливости и без остроумия. Консоль говорит фактами. Текст на экране либо сообщает то, чего человек ещё не знает, либо говорит, что сделать. Если не делает ни того, ни другого, его нет.

**Обращение.** К гостю — «вы» без панибратства и без формальных конструкций: «Спросите у мастера зала», «Покажите мастеру». Продукт про себя говорит «мы»: «мы подберём». Мастеру — инфинитивы и существительные, без «вы»: «Войти в смену», «Вернуть в наличие».

**Лаконичность.** Интерфейс говорит меньше, чем хочется. Одна мысль — одна строка. Что видно из картинки, значка или жеста, текстом не повторяем.
- Не собирать стопку «надзаголовок капсами + заголовок + пояснение + подсказка». Хватает одного-двух элементов.
- Подзаголовок — только когда сообщает неочевидное. Подзаголовок, пересказывающий заголовок или кнопки под ним, удаляется.
- Не пояснять очевидное и не оправдываться: «Без повторов: того, что выше, там не будет.», «тяните бегунки», «можно переименовать» — лишнее.
- Стрелка или кольцо уже подсказывают жест, подпись «Потяните вверх» к ним не нужна.
- Проверка: убрать строку. Если смысл не пропал, строку не возвращать.

**Канон — эта система, а не общие привычки ИИ-дизайна.** Общие гайдлайны Claude по интерфейсам и артефактам (`artifact-design`, `frontend-design-*`) здесь не действуют. Не добавлять «для полноты» eyebrow-подписи, вводные абзацы, бейджи, декоративные карточки и пояснения. Новый блок интерфейса строится из компонентов и регистров этого раздела.

**Регистр.** UPPERCASE в системе ровно в двух ролях:
- главная кнопка гостя `AromaCTA` — UPPERCASE с трекингом 0.18em: `ПОКУРИТЬ`, `ДАЛЕЕ`, `ПОКАЗАТЬ ПОДБОР`;
- шапки таблиц Мастера — UPPERCASE 10.5px, weight 500, трекинг 0.1em: `ТАБАК`, `ОСТАТОК`, `НАЛИЧИЕ`.

Всё остальное — sentence case:
- заголовки: «С чего начнём?», «Каталог миксов», «Дашборд смены»;
- вторичные кнопки, вкладки и сегменты гостя: «Изменить вкусы», «Открыть каталог сразу»;
- кнопки Мастера: «Сохранить», «Добавить табак», «Обновить код»;
- подписи секций, полей и метрик: «Состав», «Код мастера», «На полке»;
- производитель в составе: «Darkside», приглушённым цветом;
- чипы вкусов — как в данных, обычно строчными: «клубника», «лесные ягоды»; профили — с заглавной: «Цитрусовый».

**Пунктуация.**
- У кнопок и подписей точки нет. У предложений — есть.
- Перечисление — через запятую: «земляника, лесные ягоды, чёрный чай». Middot «·» в текстах интерфейса не используется, исключений нет.
- Тире не соединяет две части фразы: «X — Y» пишется двумя предложениями или через запятую. Это правило для кнопок, тостов, подсказок, ошибок и подзаголовков. Прочерк «—» в пустой ячейке таблицы остаётся: это значение, а не конструкция.
- Многоточие — только в состояниях процесса: «Проверяем код…», «Загружаем профили…». В кнопках и пунктах меню многоточия нет: «Указать остаток», а не «Осталось…».
- Кавычки — «ёлочки». В них берутся имена миксов и вердикты внутри фразы: «Три из четырёх последних выборов: «Морозная ягода».». Названия разделов, вкладок и кнопок интерфейса в кавычки не берутся: «Отметьте табак как закончившийся», а не «Нажмите «Закончился»».
- Буква «ё» пишется.

**Числа.**
- Дробное — с запятой: `4,6`, `12,5%`. Тысячи — тонким пробелом: `11 505`.
- Шаги без ведущих нулей: «Шаг 1 из 2», «Ход 1 из 3».
- Знак «≈» перед числом не ставится. Если значение оценочное, это говорится один раз — в шапке колонки или подсказке («Остаток по учёту»), а не у каждого числа.
- Множественное число согласуется руками: `1 микс / 2 микса / 5 миксов`.

**Ошибки** — что случилось и что сделать, одной-двумя фразами, без извинений и восклицаний: «Подтвердите, что вам уже исполнилось 18 лет.», «Нет связи с сервером, изменение не сохранено. Попробуйте ещё раз.»

**Пустые состояния** — факт и, если есть, следующий шаг: «Ничего не найдено. Уберите один из фильтров.», «Блокировок нет.» Никаких шуток, «Даже мастер развёл руками» и «Витрина чистая».

**Эмодзи не используются.** Ни в интерфейсе, ни в текстах. Единственные не-иконочные символы: `★` в рейтинге, `←` в гостевой навигации, `✓` в чекбоксе 18+, `⌘K` в подсказке палитры.

**Юридический минимум** всегда на гостевом гейте: бейдж «18+» и рядом обычным текстом «Курение вредит здоровью», ниже чекбокс «Мне есть 18. Понимаю, что курение вредит здоровью.» Слова предупреждения и чекбокса не меняются.

### Признаки генерации — не использовать

Эти приёмы сразу выдают текст и вёрстку, написанные нейросетью (#348). Их нет ни в новых экранах, ни в правках старых.

| Приём | Было | Стало |
|---|---|---|
| Middot как разделитель | «Шаг 01 · из 02 · Профили», «клубника · мята · лёд» | «Шаг 1 из 2», «клубника, мята, лёд» |
| Тире между частями фразы | «Спросите у мастера зала — вход открыт на 6 часов.» | «Код скажет мастер зала. Вход открыт на 6 часов.» |
| Тост «Название — текст» | «**Закончился** — снят с витрины» | «**Закончился**», ниже: «Снят с витрины.» |
| «≈» у каждого числа | «≈ 200 г» в каждой строке | «200 г», колонка «Остаток по учёту» |
| Многоточие в кнопке | «Осталось…» | «Указать остаток» |
| Название интерфейса в кавычках | «Нажмёте «Покурить» — микс появится здесь.» | «Здесь появятся миксы, которые вы выберете.» |
| Надпись UPPERCASE над заголовком | «ЛУЧШЕЕ СОВПАДЕНИЕ» над героем, «ИНВЕНТАРИЗАЦИЯ · ПТ, 23 ОКТЯБРЯ» над «Полкой» | без надписи |
| Подзаголовок-пересказ | «Полка» + «Сколько табака осталось, расход и прогноз.» | «Полка» |
| Шутка в пустом состоянии | «Даже мастер развёл руками.», «Витрина чистая.» | «Уберите один из фильтров.», «Блокировок нет.» |
| Ритмические формулы | «Закончился — одна кнопка, остаток — когда удобно», «не X, а Y», тройки «A, B и C» в каждом подзаголовке | одна обычная фраза или ничего |
| Крючок-вопрос | «Не нашли своё? Намиксуйте сами» в трёх местах | «Собрать свой микс» |

Проверка от возврата: `npm run lint:design` в `apps/master-web` проходит по исходникам обоих приложений и ловит middot, тире между частями фразы, «≈» и многоточие вне состояний процесса («Сохраняем…», «Загружаем…»). В CI это job `atelier-design-lint`.

## VISUAL FOUNDATIONS

**Цвет.** Дымчатый уголь `#141417` → `#1C1C21` → `#232329` → `#2B2B32`; текст тёплый серый в четыре ступени (`#E8E6E0` → `#6A6863`); **один** акцент — бордо `#8E2F3C` (hover `#A33B48`, deep `#5C1C26`). Текст и иконки акцентом **не** набираются: бордо на угле даёт ~2.3:1, а светлый бордо читается розовым. Подписи — `--text-muted`, активная иконка, чипы и рейтинг — кремовые, ошибки — `--danger`; бордо — только метки (черта под активной вкладкой, точка, рамка) и заливка CTA. Семантика в том же приглушённом регистре: `#6E9A6A` / `#C2A24E` / `#CF4F44` / `#5E7E96`. Двенадцать цветов вкусовых профилей (`--profile-*`) — **слой данных**, а не бренд: только точки, signature-полосы, глифы, состав и подкраска постера Витрины. Второй «фирменный» цвет вводить нельзя.

Правило одного акцента соблюдается буквально, и сплошная заливка акцентом — **только у главного CTA** (`--cta-solid`, кремовый текст `#F4EFEA`). Активный сегмент навигации и вкладки шапки — «тихие»: графит `--bg-overlay`, кремовый текст и черта акцента 2px снизу (`--segment-active-*`). Пилюля рейтинга — винный тон `--rating-*`. Тёплый янтарно-латунный градиент upstream-кода и прежний оксблад `#B04A3E` (читался оранжевым) **выведены из системы** по решению владельца бренда (2026-09-24). Единственные тёплые не-акцентные оттенки — ramp состава микса (`--composition-*`), это данные.

**Типографика.** Мастер: `Source Serif 4` (заголовки h1 36px/1.05, значения KPI 28px), `IBM Plex Sans` 11–16px для UI. **Monospace в системе нет** — служебный слой (шапки таблиц, коды смены, метрики, `⌘K`) набирается тем же `IBM Plex Sans` в роли `--font-meta`: weight 500, трекинг 0.10–0.14em, `font-variant-numeric: tabular-nums`. Выравнивание цифр даёт табличная фигура, а не моноширина. Гость: **Literata** — display-антиква для wordmark 46px, заголовков 34/28px и **названий миксов**; **Mulish** — текст 11–15px. (Upstream-стеки `Iowan Old Style` / `Avenir Next` не лицензированы и оставлены только в fallback — канон здесь Literata + Mulish.) Цифры всюду табличные.

**Отступы и сетка.** База 4px (`--space-1..10`). Гостевой экран — телефон 430px с горизонтальными полями 20px (12px под 480px); контент — CSS grid с `gap: 12px` и `align-content: start`. Консоль — до 1680px, панели с внутренним 16px, ячейки таблиц 12px, строки 36–44px. Списки и группы кнопок — всегда flex/grid + gap.

**Фон и атмосфера.** Фотографий нет вообще. Гостевой фон — вертикальный градиент угля и **одно** бордовое радиальное гало сверху по центру. Это вся атмосфера бренда: halo-кругов по углам, отдельных гало гейта, экрана «Покажите мастеру» и Миксера нет. Карточки, герой подбора, шапка листа микса и карты табаков Миксера гало не подкрашиваются, у них ровная поверхность карточки. Подкраска цветами профилей осталась только у постера Витрины, там это данные. Никаких паттернов, текстур, шума, точечных сеток и иллюстраций. Роль изображения выполняет `ProfileGlyph` — три размытых, screen-blend орба в цветах профилей. Он стоит только там, где показывает профили конкретного микса или табака. Как картинка-украшение пустого экрана, входа или приглашения он не используется. Единственное исключение — сцены раздела «Рилсы» и кружков полосы над Подбором, см. «Анимация».

**Карточки.** Гость: warm-градиент `rgba(34,34,41,.96) → rgba(24,24,28,.94)`, hairline-бордер `rgba(150,148,142,.16)`, радиус 18px (герой 22, лист 26, телефон 28), тень `0 18px 36px rgba(0,0,0,.16)` + внутренняя подсветка сверху `inset 0 1px 0 rgba(232,230,224,.04)`. Мастер: `linear-gradient(180deg, --bg-raised, --bg-base)`, радиус 12px, `--shadow-md`. Цветной левый бордер, «розовые» градиенты и скруглённые «карточки с эмодзи» — запрещены.

**Границы и тени.** Только hairline 1px из тёплого серого с альфой 0.16 / 0.26 / 0.40. Тени глубокие и мягкие (`0 24px 60px -20px rgba(0,0,0,.7)`), никогда цветные, кроме тени латунного CTA (`0 14px 26px rgba(140,45,36,.32)`). Пунктирная рамка — только у зоны перетаскивания файла, где она означает «сюда можно бросить». Пустые состояния, кнопки и панели фильтров без пунктира. Точки статуса — без ореола (`box-shadow`-кольца). Полосы прогресса и аватары — сплошной заливкой, без градиента.

**Прозрачность и блюр.** Topbar гостя — `backdrop-filter: blur(18px)` над полупрозрачным градиентом; sticky-рейл каталога — `blur(12px)`; шапка Мастера — стекло `--glass` + `blur(14px)`; overlay модалки — `rgba(0,0,0,.72)` + `blur(4px)`. Блюр применяется только к «плавающим» слоям (шапки, sticky-рейлы, оверлеи), не к контенту.

**Состояния.**
- Hover (гость): у строк меняется только бордер → `rgba(142,47,60,.40)`, без подъёма и тени. Hover (Мастер): фон `--bg-elevated`, бордер `--border-strong`.
- Active/press: `translateY(1px)` в консоли; у гостя press-состояния нет (тач).
- Selected: `--accent-soft` фон (строки таблиц); у чипов, карточек профилей, кнопок сортировки и звёзд — плотная винная заливка `--guest-chip-bg-on` + **кремовый** текст `#F7EFEC` weight 600 и светлый hairline `--guest-chip-border-on`. Акцентный текст на винной заливке не использовать — выглядит бледно.
- Focus: `outline: 2px solid var(--accent-hover); offset 2px` (гость) и `box-shadow: 0 0 0 3px var(--accent-soft)` + `--accent-border` (Мастер). Focus никогда не снимается.
- Disabled: 0.5 opacity в консоли; у CTA — тёмная винная заливка `--cta-solid-disabled-bg` и приглушённый текст.

**Анимация.** Смены состояний 120ms `ease`; прогресс-бар онбординга 240ms `cubic-bezier(.4,0,.2,1)`; bottom-sheet 240ms снизу вверх, при свайпе вниз — пружина `cubic-bezier(.22,1,.36,1)`. Единственная «характерная» анимация — `aroma-ember`: 1.6s пульсирующее бордовое кольцо. Оно стоит на одной кнопке во всём гостевом приложении — «Покурить» в листе микса. Остальные CTA, индикаторы ожидания и подсказки не пульсируют. Ожидание (#394, `design/design_handoff_loaders`): скелет будущего экрана, по которому за 1,8 с проходит светлая дымка; знак «Дым», чьи струи прорисовываются снизу вверх и тают (цикл 1,8 с, сдвиг 0,2 с), там, где формы у экрана нет; на занятой кнопке подпись остаётся, слева знак 16 px, кнопка не сереет. Текст «Загружаем…» только для скринридера, лоадер появляется через 300 мс. Всё уважает `prefers-reduced-motion`. Bounce, spring-масштабирование и параллакс не используются.

**Исключение: сцены рилсов (#153).** Владелец согласовал его 2026-10-20. Оно действует только в двух местах: в разделе «Рилсы» и в кружках полосы над Подбором. Другим экранам исключение не разрешено.
- Фон рилса — сцена на весь экран, выбранная по `flavors` микса. Она собрана из линейных мотивов: снежинки, лепестки, кольцо и дольки, грозди ягод, искры, струи дыма. Штрих знака «Дым» — 1,2–1,4, без заливки, цвет — из `--profile-*`.
- Сцена — бесшовный цикл ≈ 6 с. Играет только активный рилс, соседи и кружки полосы — статичный кадр. Тап по сцене ставит паузу.
- Док рилса появляется за 240ms (`--dur-sheet`): opacity и сдвиг на 6px, ступенькой 60ms.
- Текст — HTML-слой поверх сцены, а не часть анимации.

Остальное в силе и здесь. Акцент один: бордо — только заливка CTA и метки. Цвета профилей — слой данных. Bounce, spring и параллакса нет. При `prefers-reduced-motion` сцена — статичный кадр, док появляется без анимации. Мотивы и правило выбора сцены — в `design/design_handoff_reels/`, CSS-приближение — в гостевом ките.

**Композиция экрана.**
- Заголовок открывает экран или секцию сам: без надписи-надзаголовка (eyebrow) над ним. Подзаголовок — только если сообщает неочевидное.
- Скелет «надпись + заголовок + подпись» не повторяется на каждой карточке, диалоге и шторке. Карточка — заголовок и содержимое.
- Ряд KPI-плиток — только на Дашборде Мастера. В разделах цифры живут в чипах-фильтрах и строках, а не дублируются плитками.
- Счётчик на чипе — только когда число и есть информация: фильтры-статусы Полки («Заканчивается 3»). На чипах вкусов, профилей и фильтрах Доступа чисел нет.
- Строки подсказок клавиш под таблицами нет. Клавиши — в палитре ⌘K и в `title` кнопок.
- Иконка у текстовой кнопки — только у главного действия раздела. Исключение — «Собрать свой микс»: кнопка-контур со значком «Намиксуй» из нижней панели, чтобы приглашение не читалось строкой микса. Кнопки без текста — с иконкой и `aria-label`. В тостах иконка только у ошибки.
- `SignatureBar` — в герое подбора, листе микса, карточке для мастера, по нижней кромке постера Витрины и тонкой полосой 3px под названием в строке микса.
- Строка микса одна во всех гостевых списках (Подбор, Каталог, подборки, «Для вас», кабинет): глиф 44, название, полоса профилей, вторая строка по экрану (вкусы, причина, заметка), справа ★, если есть оценки.

**Слои и фиксированные элементы.** Гость: тонкий topbar (z 20); закреплённой панели под ним нет — карточка для мастера открывается иконкой в шапке (#289). Нижняя панель навигации (z 20) — последний flex-элемент телефона: прокрутка заканчивается над ней. На экранах знакомства, онбординга, Миксера и «Покажите мастеру» панели нет. Кроме того: док с CTA прижат к низу и накрыт fade-градиентом, sheet — z 50 от нижней кромки, ручка 40×4px. Мастер: topbar sticky `top: 8px` (z 50), палитра ⌘K — оверлей z 80, drawers-редакторы приезжают справа.

**Защита контента.** Вместо капсул — градиентные fade: док гостя (`--guest-dock-fade`) и sticky-рейл каталога с блюром. Капсулы/пилюли используются только как контролы (чипы, теги, pill-кнопки).

**Радиусы.** Два регистра: консоль 4/6/8/12/16 (чипы и статусы — 6, счётчики — 4), гость 10 (кнопки, CTA, вкладки, сегменты, поля) / 8 (чипы) / 6 (бейджи, рейтинг) / 12 (строка) / 14 (карточка) / 16 (герой) / 20 (лист) / 24 (телефон). `--r-pill` — **только** для круглых по смыслу форм: точки, свотчи, аватары, трек переключателя, полоса прогресса, ручка листа. Кнопки, вкладки и чипы пилюлями не делаются (решение владельца бренда 2026-09-24: выглядели нелепо). В CSS — только токены `--r-*`.

## ICONOGRAPHY

- Оба приложения объявляют `iconLibrary: lucide` (`components.json`) и импортируют иконки из `lucide-react`. В этой дизайн-системе Lucide подключается с CDN (`https://unpkg.com/lucide@0.470.0/dist/umd/lucide.js`) — иконочного шрифта, спрайта или собственных SVG в репозитории нет, поэтому копировать было нечего. Это единственная иконографическая подстановка (тот же самый набор, только через CDN).
- Размеры: 14–16px в консоли и шапке, 24px в нижней панели гостя, 16px и 22px на полке Витрины, 22px у сердечка карточки микса и рилса; `stroke-width` 1.8–1.9, цвет `--text-muted`. Активная иконка — кремовая (`--text-primary` / `--text-0`) при `opacity: 1`, бордо — только метка рядом: черта под табом Мастера, черта по верхней кромке пункта нижней панели (PRD §12). Иконку акцентом не красим.
- Фактически используемые иконки Мастера: `layout-dashboard`, `warehouse`, `blend`, `gallery-vertical-end`, `shield-check` (табы), `search`, `log-out`, `flame`, `star`, `triangle-alert`, `chevron-down`, `pencil`, `plus`, `eye`/`eye-off`, `lock`, `user`, `alert-circle`, `arrow-right`.
- Гость почти без иконок. Lucide есть только в пяти местах:
  - нижняя панель (#168, #151, #153): `sparkles` (Подбор), `gallery-horizontal-end` (Витрина), `clapperboard` (Рилсы), `search` (Каталог), `blend` (Миксер), `circle-user-round` (Кабинет); подписей нет, название — в `aria-label`;

  - заголовок полки Витрины (#175): слева значок типа 16px, `--text-muted` — `users` (Выбор гостей), `star` (Оценки гостей), `feather` (Редакция), `flame` (Мастера); справа шеврон `chevron-right` 22px, `--text-secondary`, при hover и focus — кремовый. Тип полки словами — в `aria-label` кнопки заголовка;
  - шапка карточки микса (#151): `heart` 22px справа, кнопка 40×40 — «В избранное». Выключено — `--text-muted`, включено — кремовое `--text-0` с заливкой `fill: currentColor`; акцентом не красим. `aria-pressed`, `aria-label` «В избранное» / «Убрать из избранного».

## Оговорки и подстановки

1. **Шрифты — решено.** Лицензий на `Iowan Old Style` и `Avenir Next` нет, поэтому канонические гостевые семейства дизайн-системы — открытые **Literata** (display) и **Mulish** (body); upstream-имена остались только в fallback-цепочке. До 2026-08-15 display-каноном была `Gelasio`, но в ней нет кириллицы (`latin`, `latin-ext`, `vietnamese`), а гостевой интерфейс целиком русский — заголовки падали в Georgia. `Literata` покрывает `cyrillic` и `cyrillic-ext`, держит тот же тёплый книжный характер и есть в variable-начертании. Мастер сохраняет `Source Serif 4` и `IBM Plex Sans` из исходника (через Google Fonts вместо fontsource). `IBM Plex Mono` из системы **удалён**: monospace-начертания не используются, его роль закрывает `--font-meta` (тот же sans с трекингом и табличными цифрами). Токен `--font-mono` оставлен алиасом на `--font-meta`, чтобы старый код не ломался.
2. **Латунь убрана, оксблад заменён на бордо — решено.** `PRD §12` требует единственного акцента, а `CTA.tsx`, `SegmentNav.tsx` и `RatingPill.tsx` в `main` рисовали янтарно-латунные градиенты. Владелец бренда выбрал канон PRD: CTA, активный сегмент и рейтинг перекрашены в акцент (`--cta-solid`, `--segment-active-*`, `--rating-*`); 2026-09-24 оксблад `#B04A3E` заменён на бордо `#8E2F3C`, а активный сегмент стал «тихим». При обратном переносе в upstream эти три компонента нужно поправить в коде.
3. **Иконки** — Lucide с CDN (в репозитории нет ни спрайта, ни шрифта, ни собственных SVG).
4. **Логотип создан здесь.** В источниках логотипа не было (только favicon-марки). По заданию владельца нарисован оригинальный знак **«Дым»**: три струи разной глубины бордо — прямая рифма к `ProfileGlyph` и `SignatureBar`. Файлы: `assets/logo-mark.svg` (на тёмной плитке), `logo-mark-oxblood.svg` (без плитки, для шапок; холст подрезан по границам рисунка — в 28-пиксельном боксе исходные поля 120×120 сжимали знак до 11px), `logo-mark-light.svg` (кремовый, на акцентной плитке), `logo-lockup.svg` (знак + wordmark + тэглайн), `favicon.svg`. Минимальный размер знака 24px по высоте самого рисунка, а не бокса; поля вокруг — не меньше высоты одной струи. Пропорции знака 54:78, поэтому задавайте высоту, а ширину оставляйте auto. Wordmark набирается Literata; для консоли — «Ателье Мастер» (Source Serif 4, 15px, tracking 0.02em): второе слово — weight 400, `--text-muted`, без разделителя.
5. **Не покрыто:** графики дашборда (`ui/chart.tsx` на Recharts) — в кит внесены как списки/KPI, без чартов; Telegram-бот (нет UI); мобильная адаптация консоли (upstream sign-off — desktop-only).
