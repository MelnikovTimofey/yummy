# Арома Ателье — Design System

Дизайн-система продукта **«Арома Ателье»** — сервиса подбора кальянных миксов для заведения. Восстановлена из исходного кода продукта (см. «Источники»), не придумана заново: все токены, шрифтовые шкалы, отступы, радиусы и компоненты сняты с рабочих приложений.

## Контекст продукта

«Арома Ателье» — три связанных контура вокруг одного каталога табаков и миксов:

| Поверхность | Что это | Кто пользуется |
|---|---|---|
| **Арома Ателье** (`apps/aroma-web`) | Гостевой mobile-first web без авторизации: 18+ gate → ежедневный код → знакомство → онбординг по вкусам → подбор / витрина / каталог → карточка микса → `Покурить` → карточка для мастера | гость заведения, вход по QR |
| **Мастер** (`apps/master-web`) | Backoffice-консоль: инвентаризация табаков, менеджер миксов, менеджер рейлов, дашборд смены, доступ (код смены, Telegram-allowlist, staff-аккаунты, журнал) | кальянный мастер, администратор |
| **Telegram-бот** (`services/telegram-bot`) | Канал раздачи ежедневного кода персоналу (не гостевой интерфейс) | персонал |

Домен: `Tobacco` → `MixComponent` → `Mix` → `Rail`. Таксономия строго разделена на три поля: `flavorProfiles` (категории-«полки»), `flavors` (конкретные ноты), `flavorTags` (мета-теги: хит, новичкам, холодок). Гость не регистрируется, избранного и истории нет; ключевое продуктовое событие — нажатие `Покурить` (`smoke_cta_clicked`), из него считаются статистические рейлы и дашборды.

Общая визуальная база обоих веб-приложений — дизайн-система **Film Noir** (PRD §12): тёмные дымчатые поверхности, тёплый туманно-серый текст, **единственный** сдержанный оксбладный акцент `#B04A3E`. Гость получает кинематографичную, «ламповую» подачу; Мастер — тот же палитрой, но плотнее и утилитарнее (control surface, не lounge UI).

## Где живут значения

Токены вынесены из скилла в пакет **`packages/design-tokens/`** — это единственное место, где заданы значения Film Noir. `tokens/*.css` здесь — тонкие реэкспорты из пакета; правка значения в них ничего не даст, менять нужно пакет.

Приложения получают канон не импортом (docker build context у каждого свой), а генератором `node packages/design-tokens/sync.mjs`, который перезаписывает коммитящиеся `apps/*/src/design-tokens.generated.css`. Расхождение ловит CI-чек `atelier-design-tokens`.

## CONTENT FUNDAMENTALS

**Язык — только русский** (инвариант PRD №1). Английский допустим лишь в именах табаков/брендов (`Darkside Wildberry`, `Cheesecake`) и в служебных ярлыках Мастера (`admin`, `master`, `/staff/audit/events`).

**Тон.** Спокойный, приглушённый, «взрослый». Заведение говорит с гостем как мастер зала: коротко, по делу, без сервисной услужливости и без юмора. Консоль говорит фактами.

**Обращение.** К гостю — «вы» без панибратства, но и без формальных конструкций: «Спросите у мастера зала», «Покажите мастеру». Продукт про себя говорит «мы»: «мы поймём, в какую сторону смотреть», «мы подберём». Мастеру — инфинитивы и существительные, без «вы»: «Войти в смену», «Вернуть в наличие».

**Регистр.**
- Кнопки-CTA гостя — UPPERCASE с трекингом 0.18em: `ПОКУРИТЬ`, `ДАЛЕЕ`, `ПОКАЗАТЬ ПОДБОР`, `ГОТОВО`.
- Микро-подписи (eyebrow, `.aroma-caps`) — UPPERCASE 11px: `ЛУЧШЕЕ СОВПАДЕНИЕ`, `СОСТАВ МИКСА`, `ПОКАЖИТЕ МАСТЕРУ`, `DARKSIDE`.
- Заголовки — sentence case: «С чего начнём?», «Каталог миксов», «Дашборд смены».
- Чипы вкусов — как в данных, обычно строчными: «клубника», «лесные ягоды»; профили — с заглавной: «Цитрусовый».
- Кнопки Мастера — sentence case: «Сохранить», «Добавить табак», «Обновить код».
- Табличные заголовки — UPPERCASE 10.5px, weight 500, трекинг 0.1em: `ТАБАК`, `ПРОИЗВОДИТЕЛЬ`, `НАЛИЧИЕ`.

**Пунктуация.** У кнопок и микро-подписей точки нет. У подзаголовков и подсказок — точка есть: «Состав, наличие и видимость на витрине.» Многоточие только в состояниях процесса: «Проверяем код…», «Собираем подбор…», «Обновляем…». Разделитель перечислений — middot: `земляника · лесные ягоды · чёрный чай`, `Витрина · Мастера`. Кавычки — «ёлочки». Буква «ё» пишется.

**Числа.** Дробное — с запятой: `4,6`, `12,5%`. Тысячи — тонким пробелом: `11 505`. Шаги — с ведущим нулём: `Шаг 01 · из 04`. Множественное число согласуется руками: `1 микс / 2 микса / 5 миксов`.

**Ошибки и пустые состояния** — одна фраза, без извинений и восклицаний: «Подтвердите, что вам уже исполнилось 18 лет.», «По выбранным фильтрам ничего не найдено.», «Нет блокировок. Витрина чистая.», «Этот микс сейчас недоступен по наличию.»

**Эмодзи не используются.** Ни в интерфейсе, ни в текстах. Единственные не-иконочные символы: `★` в рейтинге, `←` в гостевой навигации, `✓` в чекбоксе 18+, `⌘K` в подсказке палитры, `·` как разделитель.

**Юридический минимум** всегда на гостевом гейте: `18+ · Курение вредит здоровью` и чекбокс «Мне есть 18. Понимаю, что курение вредит здоровью.»

## VISUAL FOUNDATIONS

**Цвет.** Дымчатый уголь `#141417` → `#1C1C21` → `#232329` → `#2B2B32`; текст тёплый серый в четыре ступени (`#E8E6E0` → `#6A6863`); **один** акцент — оксблад `#B04A3E` (hover `#C25749`, deep `#7E342B`). Семантика в том же приглушённом регистре: `#6E9A6A` / `#C2A24E` / `#CF4F44` / `#5E7E96`. Двенадцать цветов вкусовых профилей (`--profile-*`) — **слой данных**, а не бренд: только точки, signature-полосы, глифы, состав. Второй «фирменный» цвет вводить нельзя.

Правило одного акцента соблюдается буквально: гостевой CTA (`--cta-solid`), активный сегмент навигации (`--segment-active-*`) и пилюля рейтинга (`--rating-*`) — сплошной оксблад с кремовым текстом `#F4EFEA`. Тёплый янтарно-латунный градиент, который использовал upstream-код, **выведен из системы** по решению владельца бренда. Единственные тёплые не-оксбладные оттенки, которые остались, — ramp состава микса (`--composition-*`), это данные.

**Типографика.** Мастер: `Source Serif 4` (заголовки h1 36px/1.05, значения KPI 28px), `IBM Plex Sans` 11–16px для UI. **Monospace в системе нет** — служебный слой (eyebrow, шапки таблиц, коды смены, `kbd`, метрики) набирается тем же `IBM Plex Sans` в роли `--font-meta`: weight 500, трекинг 0.10–0.14em, `font-variant-numeric: tabular-nums`. Выравнивание цифр даёт табличная фигура, а не моноширина. Гость: **Literata** — display-антиква для wordmark 46px, заголовков 34/28px и **названий миксов**; **Mulish** — текст 11–15px. (Upstream-стеки `Iowan Old Style` / `Avenir Next` не лицензированы и оставлены только в fallback — канон здесь Literata + Mulish.) Цифры всюду табличные.

**Отступы и сетка.** База 4px (`--space-1..10`). Гостевой экран — телефон 430px с горизонтальными полями 20px (12px под 480px); контент — CSS grid с `gap: 12px` и `align-content: start`. Консоль — до 1680px, панели с внутренним 16px, ячейки таблиц 12px, строки 36–44px. Списки и группы кнопок — всегда flex/grid + gap.

**Фон и атмосфера.** Фотографий нет вообще. Гостевой фон — вертикальный градиент угля плюс два оксбладных радиальных гало (сверху по центру и справа-сверху), плюс два размытых halo-круга по углам телефона; на гейте — три гало (`50% 12%`, `12% 90%`, `90% 86%`). Карточки миксов подкрашиваются радиальным гало в цвете первого профиля микса (28–33% альфы). Никаких паттернов, текстур, шума и иллюстраций. Роль изображения выполняет `ProfileGlyph` — три размытых, screen-blend орба в цветах профилей.

**Карточки.** Гость: warm-градиент `rgba(34,34,41,.96) → rgba(24,24,28,.94)`, hairline-бордер `rgba(150,148,142,.16)`, радиус 18px (герой 22, лист 26, телефон 28), тень `0 18px 36px rgba(0,0,0,.16)` + внутренняя подсветка сверху `inset 0 1px 0 rgba(232,230,224,.04)`. Мастер: `linear-gradient(180deg, --bg-raised, --bg-base)`, радиус 12px, `--shadow-md`. Цветной левый бордер, «розовые» градиенты и скруглённые «карточки с эмодзи» — запрещены.

**Границы и тени.** Только hairline 1px из тёплого серого с альфой 0.16 / 0.26 / 0.40. Тени глубокие и мягкие (`0 24px 60px -20px rgba(0,0,0,.7)`), никогда цветные, кроме тени латунного CTA (`0 14px 26px rgba(140,45,36,.32)`).

**Прозрачность и блюр.** Topbar гостя — `backdrop-filter: blur(18px)` над полупрозрачным градиентом; sticky-рейл каталога — `blur(12px)`; шапка Мастера — стекло `--glass` + `blur(14px)`; overlay модалки — `rgba(0,0,0,.72)` + `blur(4px)`. Блюр применяется только к «плавающим» слоям (шапки, sticky-рейлы, оверлеи), не к контенту.

**Состояния.**
- Hover (гость): у строк меняется только бордер → `rgba(176,74,62,.40)`, без подъёма и тени. Hover (Мастер): фон `--bg-elevated`, бордер `--border-strong`.
- Active/press: `translateY(1px)` в консоли; у гостя press-состояния нет (тач).
- Selected: `--accent-soft` фон (строки таблиц); у чипов, карточек профилей, кнопок сортировки и звёзд — плотная винная заливка `--guest-chip-bg-on` + **кремовый** текст `#F7EFEC` weight 600 и светлый hairline `--guest-chip-border-on`. Оксбладный текст на винной заливке не использовать — выглядит бледно.
- Focus: `outline: 2px solid var(--accent-hover); offset 2px` (гость) и `box-shadow: 0 0 0 3px var(--accent-soft)` + `--accent-border` (Мастер). Focus никогда не снимается.
- Disabled: 0.5 opacity в консоли; у латунного CTA — тёмная винная заливка `rgba(60,28,22,.6)` и приглушённый текст.

**Анимация.** Смены состояний 120ms `ease`; прогресс-бар онбординга 240ms `cubic-bezier(.4,0,.2,1)`; bottom-sheet 240ms снизу вверх, при свайпе вниз — пружина `cubic-bezier(.22,1,.36,1)`. Единственная «характерная» анимация — `aroma-ember`: 1.6s пульсирующее оксбладное кольцо на одном главном CTA. Всё уважает `prefers-reduced-motion`. Bounce, spring-масштабирование и параллакс не используются.

**Слои и фиксированные элементы.** Гость: topbar sticky (z 20), панель «Карточка для мастера» закреплена под ним и не скроллится, док с CTA прижат к низу и накрыт fade-градиентом, sheet — z 50 от нижней кромки, ручка 40×4px. Мастер: topbar sticky `top: 8px` (z 50), палитра ⌘K — оверлей z 80, drawers-редакторы приезжают справа.

**Защита контента.** Вместо капсул — градиентные fade: док гостя (`--guest-dock-fade`) и sticky-рейл каталога с блюром. Капсулы/пилюли используются только как контролы (чипы, теги, pill-кнопки).

**Радиусы.** Два регистра: консоль 4/6/8/12/16, гость 14 (строка) / 18 (карточка) / 22 (герой) / 26 (лист) / 28 (телефон); `999px` для всех пилюль.

## ICONOGRAPHY

- Оба приложения объявляют `iconLibrary: lucide` (`components.json`) и импортируют иконки из `lucide-react`. В этой дизайн-системе Lucide подключается с CDN (`https://unpkg.com/lucide@0.470.0/dist/umd/lucide.js`) — иконочного шрифта, спрайта или собственных SVG в репозитории нет, поэтому копировать было нечего. Это единственная иконографическая подстановка (тот же самый набор, только через CDN).
- Размеры: 14–16px, `stroke-width` 1.8–1.9, цвет `--text-muted`; активная иконка таба — `--accent` при `opacity: 1`.
- Фактически используемые иконки Мастера: `layout-dashboard`, `warehouse`, `blend`, `gallery-vertical-end`, `shield-check` (табы), `search`, `log-out`, `flame`, `star`, `triangle-alert`, `chevron-down`, `pencil`, `plus`, `eye`/`eye-off`, `lock`, `user`, `alert-circle`, `arrow-right`.
- Гостевая поверхность почти безиконочная: единственная inline-SVG — «ползунки» фильтров в каталоге (три линии, stroke 1.5). Всё остальное — типографика и `ProfileGlyph`.
- Emoji не используются. Unicode-символы — только `★` (рейтинг), `←` (назад), `✓` (18+), `↑ ↓ ×` (порядок в рейле), `⌘K`.
- Логотип — знак «Дым» (`assets/logo-mark*.svg`, `logo-lockup.svg`, `favicon.svg`), создан в рамках этой дизайн-системы: три струи в оксбладе разной глубины, stroke 5 при 120×120, round-caps. В источниках вектора не было; upstream-favicon Мастера сохранён как `logo-master-mark.svg`. Не перерисовывайте знак и не меняйте его цвета — есть готовые варианты под тёмный фон, оксблад и мелкий размер.

## Оговорки и подстановки

1. **Шрифты — решено.** Лицензий на `Iowan Old Style` и `Avenir Next` нет, поэтому канонические гостевые семейства дизайн-системы — открытые **Literata** (display) и **Mulish** (body); upstream-имена остались только в fallback-цепочке. До 2026-08-15 display-каноном была `Gelasio`, но в ней нет кириллицы (`latin`, `latin-ext`, `vietnamese`), а гостевой интерфейс целиком русский — заголовки падали в Georgia. `Literata` покрывает `cyrillic` и `cyrillic-ext`, держит тот же тёплый книжный характер и есть в variable-начертании. Мастер сохраняет `Source Serif 4` и `IBM Plex Sans` из исходника (через Google Fonts вместо fontsource). `IBM Plex Mono` из системы **удалён**: monospace-начертания не используются, его роль закрывает `--font-meta` (тот же sans с трекингом и табличными цифрами). Токен `--font-mono` оставлен алиасом на `--font-meta`, чтобы старый код не ломался.
2. **Латунь убрана — решено.** `PRD §12` требует единственного оксбладного акцента, а `CTA.tsx`, `SegmentNav.tsx` и `RatingPill.tsx` в `main` рисовали янтарно-латунные градиенты. Владелец бренда выбрал канон PRD: CTA, активный сегмент и рейтинг перекрашены в оксблад (`--cta-solid`, `--segment-active-*`, `--rating-*`). При обратном переносе в upstream эти три компонента нужно поправить в коде.
3. **Иконки** — Lucide с CDN (в репозитории нет ни спрайта, ни шрифта, ни собственных SVG).
4. **Логотип создан здесь.** В источниках логотипа не было (только favicon-марки). По заданию владельца нарисован оригинальный знак **«Дым»**: три струи разной глубины оксблада — прямая рифма к `ProfileGlyph` и `SignatureBar`. Файлы: `assets/logo-mark.svg` (на тёмной плитке), `logo-mark-oxblood.svg` (без плитки, для шапок), `logo-mark-light.svg` (кремовый, на оксбладе), `logo-lockup.svg` (знак + wordmark + тэглайн), `favicon.svg`. Минимальный размер знака 24px, поля вокруг — не меньше высоты одной струи. Wordmark набирается Literata; для консоли — `Ателье · Мастер` (Source Serif 4, 15px, tracking 0.02em).
5. **Не покрыто:** графики дашборда (`ui/chart.tsx` на Recharts) — в кит внесены как списки/KPI, без чартов; Telegram-бот (нет UI); мобильная адаптация консоли (upstream sign-off — desktop-only).
