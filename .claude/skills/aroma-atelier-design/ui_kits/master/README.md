# UI kit · Мастер (backoffice)

Кликабельная реконструкция `apps/master-web` — операционной консоли смены. Desktop-only, ширина до 1680px, горизонтальное меню вместо sidebar (решение UX-аудита).

## Сценарий

1. **Вход в смену** — split-карточка с маркой «Ателье · Мастер», логин/пароль, показ пароля. Демо: любой логин + любой пароль (`admin` даёт роль admin).
2. **Дашборд** — окно 7/14/30 дней, KPI-полоса (наличие, виден гостю, заблокировано, код смены), топ миксов недели, сигналы для команды.
3. **Табаки** — поиск, фильтры наличия и производителя, сортировка, выбор строк → batch «Вернуть в наличие» / «Убрать из наличия», тумблер наличия в строке.
4. **Миксы** — таблица каталога со статусами (виден гостю / скрыт / блокирует наличие), клик по строке → редактор состава с долями и «Распределить поровну».
5. **Рейлы** — авто-рейлы помечены «только чтение» с причиной, редактируемые открываются в составе с порядком миксов.
6. **Доступ** — код смены (mono), Telegram-allowlist операторов с привязкой chat, staff-аккаунты (admin-only), журнал операций.
7. **⌘K** — палитра «Найти или сделать» работает на любом экране (Esc закрывает).

## Файлы

- `index.html` — shell-разметка и layout-классы (перенесены из `apps/master-web/src/styles.css`)
- `MasterScreens.jsx` — Login, Dashboard, Inventory, Mixes (+editor), Rails, Access
- `MasterApp.jsx` — сессия, табы, палитра команд
- `mock-data.js` — табаки, миксы, рейлы, операторы, staff, журнал

Примитивы из бандла: `MasterTopBar`, `MasterPageHeader`, `MasterStatsRow`, `MasterList`, `MasterCard`, `MasterButton`, `MasterIconButton`, `MasterTag`, `MasterToggle`, `MasterInput`, `FilterChip`, `MasterSortPill`, `EmptyState`, `StatusPill`.

## Чего нет

Recharts-графиков дашборда (`ui/chart.tsx`), server-side пагинации и debounce-поиска, drawer-редактора табака целиком (показан редактор микса), реальных ролевых ограничений (`master` не видит admin-блоки), audit-фильтров.
