# UI kit: Мастер (backoffice)

Кликабельная реконструкция `apps/master-web`, операционной консоли смены. Desktop-only, ширина до 1680px, горизонтальное меню вместо sidebar (решение UX-аудита).

Кит отстаёт от продукта: в нём раздел «Табаки» с тумблером наличия, а в продукте с октября 2026 года Полка, Поставки, Каталог и «Что нового». Тексты и вёрстка кита переведены на канон без признаков генерации (#348). Экраны продукта по новому канону собраны в мокапе `design/design_handoff_ui_deslop/mockups-master.html`.

## Сценарий

1. **Вход в смену.** Карточка со знаком «Ателье Мастер», логин и пароль, показ пароля. Фон ровный, без гало и сетки. Демо: любой логин и любой пароль, `admin` даёт роль admin.
2. **Дашборд.** Окно 7/14/30 дней, ряд KPI (единственный в консоли): в наличии, видно гостю, заблокировано, код смены. Топ миксов недели и сигналы для команды.
3. **Табаки.** Поиск, фильтры наличия и производителя, сортировка, выбор строк и массовые действия «Вернуть в наличие» и «Убрать из наличия», тумблер наличия в строке.
4. **Миксы.** Таблица каталога со статусами (виден гостю, скрыт, блокирует наличие). Клик по строке открывает редактор состава с долями и кнопкой «Распределить поровну».
5. **Рейлы.** Авто-рейлы помечены «только чтение» с причиной, редактируемые открываются в составе с порядком миксов.
6. **Доступ.** Код смены, Telegram-allowlist операторов с привязкой chat, staff-аккаунты (только admin), журнал операций.
7. **⌘K.** Палитра «Найти или сделать» работает на любом экране, Esc закрывает.

## Файлы

- `index.html`: shell-разметка и layout-классы, перенесены из `apps/master-web/src/styles.css`
- `MasterScreens.jsx`: Login, Dashboard, Inventory, Mixes (с редактором), Rails, Access
- `MasterApp.jsx`: сессия, табы, палитра команд
- `mock-data.js`: табаки, миксы, рейлы, операторы, staff, журнал

Примитивы из бандла: `MasterTopBar`, `MasterPageHeader`, `MasterStatsRow`, `MasterList`, `MasterCard`, `MasterButton`, `MasterIconButton`, `MasterTag`, `MasterToggle`, `MasterInput`, `FilterChip`, `MasterSortPill`, `EmptyState`.

Шапка раздела состоит из заголовка и действий, надписи над заголовком нет. Подзаголовок не используется: ни один раздел кита не сообщает в нём неочевидного. У карточек только заголовок. Счётчиков на фильтрах-атрибутах нет.

## Чего нет

Recharts-графиков дашборда (`ui/chart.tsx`), серверной пагинации и поиска с debounce, редактора табака целиком (показан редактор микса), реальных ролевых ограничений (`master` не видит admin-блоки), фильтров журнала.
