# UI kit: Арома Ателье (гость)

Кликабельная реконструкция гостевого приложения `apps/aroma-web`. Mobile-first, телефон 430px в «комнате» с одним табачным гало сверху по центру. Тексты и вёрстка следуют канону без признаков генерации (#348, readme.md: «Признаки генерации — не использовать»).

## Сценарий

1. **Гейт**: wordmark и подзаголовок «Подбор кальянных миксов», поле кода (4 цифры, только подчёркивание) с подписью «Код мастера» и подсказкой «Код скажет мастер зала. Он действует до конца суток.», чекбокс 18+, табачный CTA «Войти в Ателье» без пульса. Своего гало у гейта нет. Введите любые 4 цифры и отметьте 18+.
2. **Знакомство**: 4 карточки (заголовок и одна-две фразы), пипсы, «Дальше» / «Перейти к подбору», «Пропустить знакомство». Номера шага над заголовком и водяного номера нет.
3. **Онбординг**: шаг 1 — сетка профилей 2×N и подсказка «Можно выбрать несколько.»; шаг 2 — чипы вкусов, вкусы, которых нет в миксах с выбранными профилями, бледные. Шаг показывает прогресс-бар в шапке, надписи над заголовком нет. В доке «Подходят N миксов», CTA и «Открыть каталог сразу»; если под набор миксов нет, CTA неактивна и это сказано над ней.
4. **Навигация** (#168):
   - шапка тонкая: знак, «Арома Ателье», после «Покурить» — иконка `clipboard-list` «Карточка для мастера» с точкой-меткой; кнопки смены кода нет — доступ после входа бессрочный, а случайный тап выбрасывал гостя на ввод кода;
   - разделы — в нижней панели из шести значков Lucide без подписей: Подбор, Витрина, Рилсы (#153), Каталог, Миксер, Кабинет (#151); поля панели 4 px, колонка ≈ 61 px;
   - активный пункт кремовый, над ним черта акцента;
   - панель видна на Подборе, Витрине, в Рилсах, Каталоге, Кабинете и в рейле, где активна Витрина;
   - Миксер в ките — заглушка: открывается на весь экран без панели, «←» возвращает назад;
   - Кабинет в ките — заглушка со списком избранного: входа через Telegram, истории и «Для вас» здесь нет, они в `design/design_handoff_guest_cabinet/`.
5. **Подбор**: над ним полоса рилсов (#153), ниже кнопка «Изменить вкусы», герой лучшего совпадения на ровной поверхности карточки (глиф, полоса профилей, состав, рейтинг, число выборов, CTA «Покурить» без пульса), заголовок секции «Тоже подходят» со строками микса (глиф, полоса профилей, вкусы) и в конце кнопка-контур «Собрать свой микс» со значком «Намиксуй» и подписью под ней. Надписи «Лучшее совпадение» нет. Полоса:
   - кружки 60 px со статичным кадром сцены, рамка — hairline и тонкое кольцо `--accent-border`;
   - под кружком название в две строки, 10,5 px;
   - первые восемь миксов ленты в её порядке; нажатие открывает «Рилсы» с этого микса.
6. **Рилсы** (#153) — лента миксов на всю высоту над панелью, шапки «Арома Ателье» нет:
   - без надписи «Рилсы» и счётчика — экран целиком отдан сцене (#290);
   - вертикальный свайп со снапом, один жест — один рилс; «Рилсы» в панели открывают ленту с начала;
   - порядок: подбор по онбордингу, затем остальные миксы каталога без повторов;
   - фон — сцена по `flavors` микса. Поверх неё док с fade снизу: название Literata 28 px с сердечком, вкусы через запятую, «★» (только у оценённых, без числа оценок), состав, «Подробнее» и «Покурить» без пульса;
   - док появляется за 240 мс ступенькой 60 мс; подсказка «Листайте вверх» с `chevron-up` обычным регистром и без анимации, на стартовом рилсе, пока гость не листнул;
   - тап по сцене — пауза: по центру круг 56 px с `play`;
   - «Подробнее» открывает карточку микса с кнопкой «К рилсам»; «Готово» после «Покурить» возвращает на тот же рилс.
   - после последнего микса в приложении есть слайд-приглашение в Миксер (#298). В кликабельном ките слайда нет; по канону это «Это все миксы» и «Собрать свой микс», без глифа и без «Не нашли своё?».

   Сцены — CSS-приближение мокапа `design/design_handoff_reels/`, только стиль B: линейные мотивы штрихом 1,2–1,4 без заливки, цвет из `--profile-*`, цикл ≈ 6 с, при `prefers-reduced-motion` — статичный кадр. Правило выбора сцены (`pickScene`) и мотивы скопированы из `board.jsx` мокапа. В приложении сцены — композиции Remotion. Играет только активный рилс, соседи — статичный кадр, дальше — пустые слоты.
7. **Витрина** (#175) — три полки, как в каталоге Okko:
   - заголовок полки — кнопка во всю строку: значок типа Lucide 16 px слева (`users` — Выбор гостей, `feather` — Редакция, `flame` — Мастера; `star` — Оценки гостей, в мок-данных её нет), название Literata 19 px, шеврон `chevron-right` справа; тип полки — в `aria-label`;
   - нажатие на заголовок открывает экран рейла с фильтрами по профилям; над названием подборки только «←», без крошки с типом полки и счётчика;
   - под заголовком лента постеров `ShowcaseCard` 156×92: около двух на ширину телефона, без вкусов;
   - первой — кнопка-контур «Собрать свой микс» со значком «Намиксуй», без надписи над ней; ведёт в заглушку Миксера.
8. **Каталог** (#181, вариант B):
   - sticky-рейл: поле «Микс, вкус, табак» (44 px, 16 px) и кнопка «Фильтры» с «ползунками» и числом выбранного;
   - кнопка открывает шторку, как карточку микса: подписи «Характер» и «Вкусы», чипы без счётчиков, частые первыми, поиск «Найти вкус», «Все N вкусов», CTA «Показать N миксов»; выбор применяется сразу;
   - выбранное — метками под полем одной строкой с прокруткой, касание снимает метку;
   - «N миксов» и «Сбросить»; плотные строки (знак 36 px), вкусы через запятую, совпавшие первыми, порядок по алфавиту, сортировки нет;
   - пусто: «Ничего не найдено. Уберите один из фильтров.», «Убрать: <метка>» и «Сбросить всё»; если задан только поиск — «Ничего не найдено. Измените запрос.» и «Очистить поиск». Счётчика над пустой выдачей нет;
   - частоту для порядка чипов кит считает по мок-миксам, в приложении она приходит из `/guest/onboarding/options`.
9. **Карточка микса**: bottom-sheet на ровном фоне листа, без гало профиля и без надписи об источнике над названием. Чипы, «Состав» с долями, «Ваша оценка» из 5 звёзд, «Закрыть» и «Покурить». «Покурить» здесь единственная кнопка гостя с пульсом `aroma-ember`. Справа в шапке — сердечко `heart` 22 px (#151): выключено `--text-muted`, включено кремовое с заливкой; отмеченный микс появляется в Кабинете.
10. **Рейтинг** (#185) — «★» только у миксов с оценками гостей. У «Тропиков», «Лимонного пирога» и «Bodrum Tangerine» в мок-данных `ratingsCount: 0`: рейтинга нет ни в Подборе, ни на постере Витрины, ни в рейле, ни в Каталоге.
11. **Карточка для мастера**: после «Покурить» чистый экран на ровном фоне. Сверху строка «Покажите мастеру» и «Готово», ниже глиф 96px, название, профили через запятую, полоса профилей и состав без подписи. Зафиксированный микс доступен иконкой `clipboard-list` в шапке (#289); закреплённой панели под topbar больше нет. Собранный в «Намиксуй» микс — тоже карточка для мастера (#291).

## Файлы

- `index.html` — оболочка, экранные layout-классы (перенесены из `apps/aroma-web/src/styles.css` и переведены на канон #348), загрузка бандла дизайн-системы. Подпись поля кода `AccessCodeInput` рисует классом `.aroma-caps`, здесь она до правки компонента переопределена в sentence case
- `GuestScreens.jsx` — экраны (Access, Intro, Onboarding, Recommendations, Showcase, Catalog, CatalogFiltersSheet, Rail, MixSheet с сердечком, Confirmation), кнопка-приглашение `MixerInvite`, рилсы (`pickScene`, `Scene`, `ReelStrip`, `Reel`, `ReelsScreen`) и `Icon` — значок Lucide из UMD-сборки с CDN
- `GuestApp.jsx` — тонкая шапка, нижняя панель `BottomNav` на шесть пунктов, заглушки Миксера и Кабинета, избранное, лента рилсов и возврат на рилс после «Покурить», переходы, фильтры Каталога и их шторка, правило рекомендаций (совпадение профилей ×3 + вкусов ×2 + популярность)
- `mock-data.js` — 12 реальных миксов и 3 рейла из `docs/data/mixes.md`; у трёх миксов `ratingsCount: 0`

Примитивы берутся из бандла дизайн-системы (`window.<Namespace>`): `AromaCTA`, `AromaChip`, `GuestTab`, `ProfileGlyph`, `SignatureBar`, `RatingPill`, `ProfileCard`, `MixRow`, `ShowcaseCard`, `GuestCard`, `CompositionStack`, `AccessCodeInput`, `OnboardingProgress`.

## Чего нет

Реального API (`VITE_API_BASE_URL`), свайпа вниз для закрытия листа и шторки «Фильтры» (в исходнике — pointer-жест с порогом 110px), `aria-label` у чипов (`AromaChip` его не принимает), сохранения состояния в localStorage, аналитических событий, пересчёта рейтинга после оценки (в приложении «★» появляется сразу после первой оценки гостя). В рилсах нет Remotion, ленты вошедшего гостя («Для вас», причины, пузырь, «Выбирали N раз»), шторки сердечка без входа и состояний «Микс закончился» и «Пусто» — они в `design/design_handoff_reels/`.
