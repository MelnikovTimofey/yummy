# UI kit · Арома Ателье (гость)

Кликабельная реконструкция гостевого приложения `apps/aroma-web`. Mobile-first, телефон 430px в «комнате» с оксбладными гало.

## Сценарий

1. **Гейт** — wordmark, поле кода (4 цифры, только подчёркивание), чекбокс 18+, латунный CTA «Войти в Ателье». Введите любые 4 цифры и отметьте 18+.
2. **Знакомство** — 4 карточки с watermark-номером шага, пипсы, «Дальше» / «Перейти к подбору», «Пропустить знакомство».
3. **Онбординг** — шаг 1: сетка профилей 2×N; шаг 2: чипы вкусов + «Сейчас выбрано». Прогресс-бар и «Открыть каталог сразу» в доке.
4. **Подбор** — герой лучшего совпадения (глиф, состав, рейтинг, число выборов, пульсирующий CTA) + «Тоже подходят».
5. **Витрина** — три рейла (Выбор гостей / Редакция / Мастера) с горизонтальными карточками и дашед-кнопкой «Все» → экран рейла с фильтрами по профилям.
6. **Каталог** — sticky-рейл с поиском, чипы профилей, поповер сортировки и вкусов, счётчик «Найдено · N».
7. **Карточка микса** — bottom-sheet: состав с долями, чипы, 5 звёзд, «Закрыть» + «Покурить».
8. **Карточка для мастера** — после «Покурить»: чистый экран с глифом 96px, названием, профилями и составом; сверху «Готово». Зафиксированный микс остаётся закреплённой панелью под topbar.

## Файлы

- `index.html` — оболочка, экранные layout-классы (перенесены из `apps/aroma-web/src/styles.css`), загрузка бандла дизайн-системы
- `GuestScreens.jsx` — экраны (Access, Intro, Onboarding, Recommendations, Showcase, Catalog, Rail, MixSheet, Confirmation)
- `GuestApp.jsx` — переходы, фильтры, правило рекомендаций (совпадение профилей ×3 + вкусов ×2 + популярность)
- `mock-data.js` — 12 реальных миксов и 3 рейла из `docs/data/top-20-mixes.md`

Примитивы берутся из бандла дизайн-системы (`window.<Namespace>`): `AromaCTA`, `AromaChip`, `SegmentNav`, `GuestTab`, `ProfileGlyph`, `SignatureBar`, `RatingPill`, `ProfileCard`, `MixRow`, `ShowcaseCard`, `GuestCard`, `CompositionStack`, `AccessCodeInput`, `OnboardingProgress`.

## Чего нет

Реального API (`VITE_API_BASE_URL`), свайпа вниз для закрытия листа (в исходнике — pointer-жест с порогом 110px), сохранения состояния в localStorage, аналитических событий.
