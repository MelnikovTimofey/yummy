Tonal status tag — the console's only coloured surface besides the accent.

```jsx
<MasterTag tone="success" dot>виден гостю</MasterTag>
<MasterTag tone="warning">блокирует наличие</MasterTag>
<MasterTag tone="ghost">только чтение</MasterTag>
```

Lowercase Russian labels; tone carries the meaning (success = visible to guests, warning = inventory-blocked, accent = read-only/auto rail).
