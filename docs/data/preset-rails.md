# Редакторские рейлы Арома Ателье

`prepared`-рейлы для Главной гостя (`PRD.md` §7). Рейл — это не список
миксов, а **правило**: смысл подборки, записанный над таксономией табаков.
`build:catalog` сам раскладывает по правилам пул из [`mixes.md`](mixes.md)
в порядке пула (чем выше строка, тем востребованнее микс). Новый микс в пуле
попадает во все подходящие рейлы без правки этого файла.

Шесть рейлов — «народные», из хитов: ягоды, цитрусы, тропики, лёд, напитки,
десерты. Четыре — для ценителей, из ниши: чай и пряности, крепкая база,
травы и цветы, гастрономия. Часть названий атмосферные, часть прямые —
чтобы гость на Главной сразу видел, где что лежит.

## Грамматика правила

Части правила разделены « · », внутри части альтернативы — через `|`
(в ячейке таблицы — `\|`), несколько групп — через запятую. Термин — это
профиль (`berry`, `floral_herbal`), вкус (`манго`, `чай`), мета-тег
(`охлаждающий`, `напитки`, `редкие`) или крепость табака строчными
(`крепкая`) — как они лежат в каталоге `Tobacco`.

| Часть | Смысл |
|---|---|
| `хиты` / `ниша` | Из какого набора пула брать миксы; без неё — из обоих. |
| `основа a\|b` | Табаки с `a` или `b` дают ≥ 40% микса: это ведущая нота, а не штрих. |
| `есть a\|b` | Хотя бы один табак с `a` или `b`, доля любая. |
| `без a, b` | Ни одного табака с `a` или `b`. |
| `до N табаков` | В составе не больше N табаков. |

Незнакомая часть правила — ошибка сборки, а не молчаливый пропуск.

## Раскладка

- В рейле до 8 миксов, в порядке пула.
- Один микс — не больше чем в двух рейлах, иначе один хит займёт всю
  Главную. Рейлы разбираются сверху вниз: верхние забирают лучшие миксы
  первыми.
- Рейл меньше 5 миксов — стоп сборки: правило или пул нужно поправить.
- Микс с табаком, который снят с производства или закончился, в сборку не
  попадает. Если табак закончится позже, гость микс не увидит
  (`PRD.md` §6.2), а рейл с < 2 видимыми миксами на Главной не показывается.

Правка состава после сборки — через `Мастер → Менеджер рейлов`; следующий
прогон `build:catalog` пересоберёт `rail-prepared-*` из этого файла заново.
